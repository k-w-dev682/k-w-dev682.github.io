# Dziedzina — zadania e–g, logarytmy i wykładniki

## e) <Eq tex={String.raw`f(x)=\frac{2}{2^x-4}`}/>

Mianownik ≠0, zatem `2ˣ≠4=2²`. Wniosek: x≠2. **Dziedzina:** wszystkie rzeczywiste poza 2.

## f) <Eq tex={String.raw`f(x)=\sqrt{\log_{0{,}1}\!\left(\frac{3x-1}{2x+1}\right)}`}/>

Krok 1. Argument logarytmu musi być dodatni:

<Eq display tex={String.raw`\frac{3x-1}{2x+1}>0`}/>

Co daje x &lt; −1/2 albo x>1/3.

Krok 2. Pierwiastek istnieje, gdy logarytm jest ≥0. Ponieważ podstawa 0,1 leży pomiędzy 0 i 1, nierówność odwraca kierunek:

<Eq display tex={String.raw`0<\frac{3x-1}{2x+1}\le1`}/>

Po rozwiązaniu i połączeniu warunków otrzymujemy:

<Eq display tex={String.raw`D=\left(\frac13,2\right]`}/>

## g) Logarytm z podstawą zależną od x

Na zdjęciu 22–26 widać przykład z podstawą <Eq tex={String.raw`x^2-3`}/> i argumentem <Eq tex={String.raw`x^2+2x+3`}/>.

**Trzy warunki:** podstawa >0, podstawa ≠1, argument >0. Drugi wielomian jest zawsze dodatni, bo jego wyróżnik jest ujemny, a współczynnik przy x² dodatni.

Dla podstawy: x²−3>0, więc |x|>√3; dodatkowo x²−3≠1, więc x≠±2.

**Dziedzina:** (−∞,−2) ∪ (−2,−√3) ∪ (√3,2) ∪ (2,∞). Jeśli inne znaki w Twoim oryginalnym przykładzie były zamierzone, zerknij na [listę niejasności](../niejasnosci/).
