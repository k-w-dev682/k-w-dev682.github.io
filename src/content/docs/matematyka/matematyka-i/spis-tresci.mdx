## Ścieżka nauki — od prostych po trudniejsze

**1. Logika:** zdania → spójniki → implikacje → prawa → tabele prawdy → kwantyfikatory.

**2. Zbiory:** element i podzbiór → działania → przedziały → relacje → dowody zbiorowe.

**3. Funkcje:** argument i wynik → dziedzina → funkcje elementarne → własności → moduł → funkcje odwrotne.

**4. Praktyka:** zadania z zeszytu → rozwiązania samodzielne → powtórka najczęstszych błędów.

Jeśli jakiś temat wydaje się trudny, sprawdź najpierw jego poprzednik w tej ścieżce. W Matematyce I wiele problemów wynika z nieopanowanego wcześniejszego symbolu, a nie z trudności aktualnego wzoru.
