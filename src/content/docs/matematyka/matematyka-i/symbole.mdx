# Słownik symboli — Matematyka I

| Symbol | Czytamy | Znaczenie |
|---|---|---|
| ∈ | należy do | element zbioru |
| ∉ | nie należy do | nie jest elementem |
| ⊆ | zawiera się | każdy element pierwszego należy do drugiego |
| ∅ | zbiór pusty | brak elementów |
| ∪ | suma | w A lub B |
| ∩ | część wspólna | w A i B |
| ∖ | różnica | w A, lecz nie w B |
| ¬ | negacja | nie |
| ∧ | koniunkcja | i |
| ∨ | alternatywa | lub |
| ⇒ | implikacja | jeśli…, to… |
| ⇔ | równoważność | wtedy i tylko wtedy |
| ∀ | dla każdego | wszystkie elementy |
| ∃ | istnieje | co najmniej jeden |
| ℕ | naturalne | uwaga na przyjętą konwencję zera |
| ℤ | całkowite | …, −2, −1, 0, 1, 2, … |
| ℚ | wymierne | ilorazy całkowitych |
| ℝ | rzeczywiste | liczby na osi liczbowej |
| D | dziedzina | dozwolone argumenty funkcji |
| `f⁻¹` | funkcja odwrotna | zamienia argument z wartością |

**Notacja:** zapis aᵇ oznacza potęgę, natomiast symbol `f⁻¹` nie oznacza liczby `1/f(x)` — to zupełnie inna operacja.

## Jak szybko nauczyć się czytać matematykę?

Ćwicz **tłumaczenie w obie strony**: od symboli do zwykłych słów i od słów do symboli. Na przykład `x∈A∩B` czytasz: „x należy **jednocześnie** do zbioru A oraz do B”. Z kolei „x należy do A lub do B” zapisujesz `x∈A∪B`.

**Nie myl:** `∈` łączy element ze zbiorem, a `⊆` łączy zbiór ze zbiorem. `f⁻¹` oznacza funkcję odwrotną, a `1/f(x)` to odwrotność liczby będącej wynikiem funkcji.

<details className="m1-selfcheck">
<summary>Mini-trening: przeczytaj `∀x∈A ∃y∈B: x<y`</summary>

„Dla każdego x należącego do A istnieje przynajmniej jedno y należące do B, które jest większe od x”. Kolejność „dla każdego” i „istnieje” ma znaczenie.
