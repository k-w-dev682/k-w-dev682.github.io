# Ćwiczenia ze zbiorów: sumy, różnice, nierówności

## Zadanie 1. Podaj elementy zbioru

<Eq display tex={String.raw`A=\{x\in\mathbb{N}:x^2\le 7\}`}/>

Dla dodatnich naturalnych: 1²≤7, 2²≤7, 3²>7. Zatem A to **1 i 2**.

## Zadanie 2. Iloczyn zbiorów opisanych nierównościami

A to liczby rzeczywiste mniejsze od 1, B — liczby rzeczywiste mniejsze od 2.

- A = (−∞,1)
- B = (−∞,2)
- A ∪ B = (−∞,2)
- A ∩ B = (−∞,1)
- B ∖ A = [1,2)

Ponieważ A jest podzbiorem B, różnica A ∖ B jest pusta.

## Zadanie 3. Moduły i zbiory

<Eq display tex={String.raw`A=\{x\in\mathbb{R}:|x-1|<3\}`}/>
<Eq display tex={String.raw`B=\{x\in\mathbb{R}:|x+1|>4\}`}/>

**A:** −3 &lt; x−1 &lt; 3, stąd −2 &lt; x &lt; 4.

**B:** x+1 &lt; −4 lub x+1 > 4, stąd x &lt; −5 lub x > 3.

- A ∩ B = (3,4)
- A ∪ B = (−∞,−5) ∪ (−2,∞)

<div className="mathi-note">Niektóre odręczne nierówności są zamazane. Podane tutaj przekształcenia zostały policzone od nowa i sprawdzone.</div>
