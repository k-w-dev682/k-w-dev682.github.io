# Ciągi: wyraz jawny i rekurencja

Ciąg to uporządkowana lista wyrazów: <Eq tex={String.raw`a_1,a_2,a_3,\ldots`}/>. **Indeks**, czyli mała liczba na dole, oznacza pozycję w ciągu, a nie mnożenie.

## Wzór jawny

<Eq display tex={String.raw`a_n=2n^2-1`}/>

Aby obliczyć <Eq tex={String.raw`a_4`}/>, podstawiamy n = 4:

<Eq display tex={String.raw`a_4=2\cdot4^2-1=2\cdot16-1=31`}/>

Wzór jawny pozwala wyliczyć wyraz bez znajomości poprzednich.

## Wzór rekurencyjny

<Eq display tex={String.raw`a_n=2a_{n-1}+3a_{n-2}\qquad(n\ge3)`}/>

Aby obliczyć nowy wyraz, potrzebujemy **dwóch poprzednich**. Musimy znać również dwa wyrazy początkowe. W notatkach nie było jednoznacznych warunków startowych — poniższy przykład jest **dodatkową ilustracją**, nie odtworzoną informacją z wykładu.

Przyjmijmy: <Eq tex={String.raw`a_1=1`}/> i <Eq tex={String.raw`a_2=2`}/>.

<Eq display tex={String.raw`a_3=2a_2+3a_1=2\cdot2+3\cdot1=7`}/>
<Eq display tex={String.raw`a_4=2a_3+3a_2=2\cdot7+3\cdot2=20`}/>

<RecurrenceLab client:load />

:::tip[Zapamiętaj]
**Wzór jawny** mówi, jak policzyć dowolny wyraz od razu. **Wzór rekurencyjny** mówi, jak dojść do niego z wcześniej poznanych wyrazów.
:::
