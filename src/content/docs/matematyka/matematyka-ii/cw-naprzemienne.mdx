# Zadanie 1d — naprzemienna suma kwadratów

<Eq display tex={String.raw`\sum_{k=1}^{n}(-1)^{k-1}k^2=(-1)^{n-1}\frac{n(n+1)}2`}/>

Symbol <Eq tex={String.raw`(-1)^{k-1}`}/> zmienia znak kolejnych składników: gdy wykładnik jest parzysty daje **+1**, gdy nieparzysty daje **−1**.

## Podstawienie dla n = 4

Lewa strona: 1² − 2² + 3² − 4² = 1 − 4 + 9 − 16 = **−10**.

Prawa strona:

<Eq display tex={String.raw`(-1)^{4-1}\frac{4(4+1)}2=(-1)^3\cdot10=-10`}/>

## Dowód indukcyjny

**Baza n = 1:** obie strony = 1.

**Założenie:** przyjmij wzór dla n.

**Krok n+1:** dodaj nowy wyraz <Eq tex={String.raw`(-1)^n(n+1)^2`}/>:

<Eq display tex={String.raw`\begin{aligned}L&=(-1)^{n-1}\frac{n(n+1)}2+(-1)^n(n+1)^2\\&=(-1)^n\left[-\frac{n(n+1)}2+(n+1)^2\right]\\&=(-1)^n(n+1)\left[-\frac n2+n+1\right]\\&=(-1)^n\frac{(n+1)(n+2)}2=P\end{aligned}`}/>

Dlaczego przy wyłączaniu <Eq tex={String.raw`(-1)^n`}/> pojawia się minus? Bo <Eq tex={String.raw`(-1)^{n-1}=-(-1)^n`}/>.
