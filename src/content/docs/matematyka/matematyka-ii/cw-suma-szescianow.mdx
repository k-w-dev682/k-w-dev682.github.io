# Zadanie 1b — suma sześcianów

<Eq display tex={String.raw`\sum_{k=1}^{n}k^3=\left(\frac{n(n+1)}2\right)^2`}/>

To bardzo ciekawy wzór: suma sześcianów jest **kwadratem sumy liczb od 1 do n**.

## Podstawienie dla n = 3

<Eq display tex={String.raw`1^3+2^3+3^3=1+8+27=36`}/>
<Eq display tex={String.raw`\left(\frac{3\cdot4}2\right)^2=6^2=36`}/>

## Dowód indukcyjny

**Baza n = 1:** 1 = (1·2/2)² = 1.

**Założenie:** dla n suma sześcianów wynosi n²(n+1)²/4.

**Krok:** dopisujemy (n+1)³ i upraszczamy.

<Eq display tex={String.raw`\begin{aligned}L&=\sum_{k=1}^{n}k^3+(n+1)^3\\&=\frac{n^2(n+1)^2}4+(n+1)^3\\&=\frac{(n+1)^2}4\big(n^2+4(n+1)\big)\\&=\frac{(n+1)^2}4(n^2+4n+4)\\&=\frac{(n+1)^2(n+2)^2}4=P\end{aligned}`}/>

**Dlaczego ostatni krok działa?** Ponieważ <Eq tex={String.raw`n^2+4n+4=(n+2)^2`}/>. To wzór skróconego mnożenia <Eq tex={String.raw`(a+b)^2=a^2+2ab+b^2`}/> z a = n, b = 2.

:::tip[Sprawdź sam]
Dla n = 4: 1 + 8 + 27 + 64 = 100, a (4·5/2)² = 100.
:::
