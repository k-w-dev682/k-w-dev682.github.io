## Co właściwie mówi wzór na sześciany?

`k³` to `k·k·k`. Suma sześcianów od 1 do `n` okazuje się **kwadratem** sumy zwykłych liczb od 1 do `n`.

### Dlaczego w dowodzie zmienia się `(n+1)³` na czwórkę w liczniku?

Po dodaniu nowego składnika w kroku indukcyjnym mamy:

<Eq display tex={String.raw`\frac{n^2(n+1)^2}{4}+(n+1)^3`}/>

Drugi składnik zapisujemy jako `4(n+1)³/4`, żeby oba miały mianownik 4. Wyłączamy wspólny czynnik `(n+1)²`:

<Eq display tex={String.raw`\frac{(n+1)^2[n^2+4(n+1)]}{4}`}/>

W nawiasie otrzymujemy `n²+4n+4`, czyli `(n+2)²`. Dlatego cały ułamek jest kwadratem `(n+1)(n+2)/2`, zgodnie ze wzorem dla `n+1`.


<Eq display tex={String.raw`\sum_{k=1}^{n}k^3=\left(\frac{n(n+1)}2\right)^2`}/>

To bardzo ciekawy wzór: suma sześcianów jest **kwadratem sumy liczb od 1 do n**.

## Podstawienie dla n = 3

<Eq display tex={String.raw`1^3+2^3+3^3=1+8+27=36`}/>
<Eq display tex={String.raw`\left(\frac{3\cdot4}2\right)^2=6^2=36`}/>

## Dowód indukcyjny

**Baza n = 1:** 1 = (1·2/2)² = 1.

**Założenie:** dla n suma sześcianów wynosi n²(n+1)²/4.

**Krok:** dopisujemy (n+1)³ i upraszczamy.

<Eq display tex={String.raw`\begin{aligned}L&=\sum_{k=1}^{n}k^3+(n+1)^3\\&=\frac{n^2(n+1)^2}4+(n+1)^3\\&=\frac{(n+1)^2}4\big(n^2+4(n+1)\big)\\&=\frac{(n+1)^2}4(n^2+4n+4)\\&=\frac{(n+1)^2(n+2)^2}4=P\end{aligned}`}/>

**Dlaczego ostatni krok działa?** Ponieważ <Eq tex={String.raw`n^2+4n+4=(n+2)^2`}/>. To wzór skróconego mnożenia <Eq tex={String.raw`(a+b)^2=a^2+2ab+b^2`}/> z a = n, b = 2.

:::tip[Sprawdź sam]
Dla n = 4: 1 + 8 + 27 + 64 = 100, a (4·5/2)² = 100.
:::

## Dlaczego suma sześcianów daje kwadrat sumy?

Tożsamość `1³+2³+...+n³=[n(n+1)/2]²` wygląda niespodziewanie. Prawa strona to po prostu **kwadrat sumy pierwszych n liczb naturalnych**.

### Jeden przykład rozłożony na małe kroki

1. Dla `n=3` policz sześciany: `1³+2³+3³=1+8+27=36`.
2. Policz zwykłą sumę `1+2+3=6` i jej kwadrat: `6²=36`.
3. Załóż `Sₙ=[n(n+1)/2]²`. Dodaj nowy sześcian: `Sₙ₊₁=[n(n+1)/2]²+(n+1)³`.
4. Wyłącz `(n+1)²`: `(n+1)²[n²/4+(n+1)]`.
5. Zrób wspólny mianownik 4: `n²+4n+4=(n+2)²`. Otrzymasz `(n+1)²(n+2)²/4=[(n+1)(n+2)/2]²`.

### Dlaczego to działa, a nie jest tylko regułką?

Wyrażenie `n²+4n+4` jest **kwadratem sumy** `(n+2)²`. To właśnie krok prowadzący do tezy.

:::tip[Zapamiętaj jednym zdaniem]
**Suma sześcianów = (suma pierwszych n liczb)².**
:::

### Błąd, który najłatwiej popełnić

Nie pomyl sumy sześcianów z sześcianem sumy: `1³+2³=9`, natomiast `(1+2)³=27`.

<details className="m2-selfcheck">
<summary>Spróbuj sam: Ile wynosi `1³+2³+3³+4³`?</summary>

**Rozwiązanie z wyjaśnieniem:** Najpierw `1+2+3+4=10`, potem `10²=100`. Kontrola: `1+8+27+64=100`.

</details>
