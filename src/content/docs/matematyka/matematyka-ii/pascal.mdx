# Trójkąt Pascala i tożsamość Pascala

W trójkącie Pascala **na brzegach są jedynki**, a każda liczba wewnątrz jest sumą dwóch liczb bezpośrednio nad nią.

## Reguła Pascala

<Eq display tex={String.raw`\binom nk+\binom n{k+1}=\binom{n+1}{k+1}`}/>

Podobnie można zapisać:

<Eq display tex={String.raw`\binom n{k-1}+\binom nk=\binom{n+1}k`}/>

Drugi wariant wymaga 1 ≤ k ≤ n. Pierwszy używamy dla 0 ≤ k &lt; n.

### Liczbowy przykład

<Eq display tex={String.raw`\binom42+\binom43=6+4=10=\binom53`}/>

## Skąd wzięło się to dodawanie?

Przy wyborze grupy z n+1 osób wskaż jedną wyróżnioną osobę. Szukana grupa **zawiera ją** albo **jej nie zawiera**. Oba przypadki nie zachodzą jednocześnie i razem wyczerpują możliwości. To kombinatoryczne uzasadnienie reguły Pascala.
