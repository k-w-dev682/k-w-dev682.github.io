# `setprecision` i formatowanie wyniku

## Zrozum od podstaw

Wartość w pamięci i tekst na ekranie to dwie różne rzeczy. Ten sam wynik możesz pokazać krótko lub z wieloma cyframi. Manipulatory strumienia zmieniają sposób wypisywania, podobnie jak ustawienie liczby miejsc w kalkulatorze.

Nagłówek iomanip udostępnia setprecision. W zwykłym trybie liczba oznacza cyfry znaczące. Przy fixed oznacza miejsca po kropce. Ustawienia pozostają aktywne dla kolejnych wypisań do tego strumienia, dopóki ich nie zmienisz.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double x = 123.456789;
    std::cout << std::setprecision(4) << x << '\n';
    std::cout << std::fixed << std::setprecision(4) << x << '\n';
    std::cout << std::defaultfloat << std::setprecision(6) << x << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. x otrzymuje przybliżenie liczby 123.456789.
2. Cztery cyfry znaczące dają 123.5.
3. fixed i cztery miejsca po kropce dają 123.4568.
4. defaultfloat wraca do zwykłego trybu; precyzję 6 ustawiamy osobno. Wynik to 123.457.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
std::cout << std::setprecision(2) << x;
```

Sama precyzja 2 nie oznacza dwóch miejsc po kropce. Dla kwoty pokazanej z dwoma miejscami potrzebujesz fixed.

**Poprawiony fragment:**

```cpp
std::cout << std::fixed << std::setprecision(2) << x;
```

### 1. Jak wypisać 2 jako 2.00?

<details>

## Zapamiętaj i sprawdź rozumienie

fixed + setprecision oznacza miejsca po kropce. Formatowanie nie zwiększa dokładności obliczeń.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Wartość a sposób jej wyświetlania

Liczba przechowywana w `double` może mieć więcej cyfr, niż wypisuje domyślnie `std::cout`. To oznacza, że **sposób formatowania nie zmienia automatycznie wartości w pamięci**.

```cpp
#include <iostream>
#include <iomanip>
int main() {
    double x = 1.0 / 3.0;
    std::cout << std::setprecision(4) << x << '\n';
    std::cout << std::fixed << std::setprecision(4)
              << x << '\n';
}
```

W pierwszym wierszu `setprecision(4)` oznacza najczęściej **cztery cyfry znaczące**; przy `fixed` oznacza **cztery miejsca po kropce**. Dla `1/3` zobaczysz odpowiednio `0.3333` i `0.3333` — tu akurat wygląda podobnie, ale dla `123.4567` różnica byłaby wyraźna.

## Kiedy formatowanie jest przydatne?

Przy wypisywaniu wyników zadań, porównywaniu precyzji `float` z `double` i badaniu, czy dwa wyniki różnią się na dalszych miejscach.

## Zadanie

Wypisz `123.456789` raz z `setprecision(4)`, drugi raz z `fixed << setprecision(4)`. Porównaj liczby widocznych miejsc.
