# `size`, `substr`, `find`, `erase`, `insert`

## Zrozum od podstaw

Metody string są narzędziami o różnych skutkach: substr tworzy nowy napis, a erase zmienia oryginał. find wyszukuje i zwraca pozycję; npos oznacza brak wyniku. Nie traktuj każdej zwróconej liczby jak poprawnego indeksu.

W substr(p, n) drugi argument jest liczbą elementów, nie indeksem końca. W erase(p, n) także podajemy liczbę usuwanych elementów. Po zmianie napisu dawne pozycje mogą już wskazywać inne znaki.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Ala ma kota";
    auto p = s.find("kota");
    if (p != std::string::npos) {
        std::string fragment = s.substr(p, 4);
        s.erase(p, 4);
        s.insert(p, "psa");
        std::cout << fragment << " / " << s << '\n';
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. auto pozwala kompilatorowi dobrać typ wyniku find. Pozycja kota wynosi 7.
2. != npos chroni przed użyciem znacznika braku wyniku jako pozycji.
3. substr kopiuje cztery znaki do fragment; nie zmienia s.
4. erase usuwa kota, insert wstawia psa w tym samym miejscu. Wynik: kota / Ala ma psa.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
if (s.find("Ala")) std::cout << "Jest";
```

Pozycja 0 jest poprawnym wynikiem, ale w warunku logicznym oznacza fałsz. Znacznik npos jest niezerowy, więc błędna wersja odwraca sens części przypadków.

**Poprawiony fragment:**

```cpp
if (s.find("Ala") != std::string::npos) std::cout << "Jest";
```

## Gotowe narzędzia do manipulacji tekstem

Nie musisz przepisywać napisu znak po znaku za każdym razem. `std::string` udostępnia metody:

```cpp
std::string s = "Ala ma kota";
std::cout << s.size() << '\n';     // 11
std::cout << s.substr(4, 2);      // "ma"
std::cout << s.find("kot");     // 7
s.erase(3, 1);                    // usuń spację po "Ala"
```

| Metoda | Działanie | Na co uważać? |
|---|---|---|
| `size()` / `length()` | Liczba elementów `char` | UTF-8 to nie zawsze liczba liter |
| `substr(p,n)` | Kopia `n` elementów od `p` | Start od 0 |
| `find(t)` | Pozycja pierwszego wystąpienia | Może zwrócić `std::string::npos` |
| `insert(p,t)` | Wstaw fragment | Musi istnieć poprawna pozycja |
| `erase(p,n)` | Usuń fragment | Modyfikuje oryginalny napis |

## Przykład wyszukiwania

```cpp
std::string zdanie = "Ala ma kota";
auto gdzie = zdanie.find("kot");
if (gdzie != std::string::npos) {
    std::cout << "Znaleziono na pozycji " << gdzie;
}
```

`npos` nie jest normalną pozycją. To specjalna wartość informująca, że fragment **nie został znaleziony**.
