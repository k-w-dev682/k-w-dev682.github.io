# Od zera: jak myśli komputer?

## Zrozum od podstaw

Program to lista poleceń, a nie życzenie. Pomyśl o przepisie na kanapkę: „zrób dobrą kanapkę” pozostawia wiele decyzji, ale „weź dwie kromki” jest konkretną instrukcją. Komputer potrzebuje właśnie konkretnych kroków. W tym przykładzie nie pobieramy danych z klawiatury: liczby są zapisane w kodzie. To pozwala najpierw zrozumieć samą kolejność wykonania.

**Kod źródłowy** to tekst, który piszesz. **Instrukcja** to pojedyncze polecenie. **Wynik** to informacja otrzymana po wykonaniu poleceń. Program zaczyna wykonywanie własnego kodu w funkcji `main`, a nie od instrukcji `#include`.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    int a = 2;
    int b = 3;
    int suma = a + b;
    std::cout << suma << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. `int a = 2;` tworzy zmienną całkowitą o nazwie a i zapisuje w niej 2.
2. `int b = 3;` tworzy drugie, niezależne miejsce na wartość.
3. `+` dodaje odczytane wartości; `=` zapisuje wynik 5 do suma.
4. `std::cout` wypisuje 5. `<<` przekazuje dane do wyjścia, a `\n` przechodzi do nowej linii.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
std::cout << "suma";
```

Cudzysłowy oznaczają dosłowny tekst. Pierwsza wersja wypisuje cztery litery, druga odczytuje wartość zmiennej.

**Poprawiony fragment:**

```cpp
std::cout << suma;
```

## Zapamiętaj i sprawdź rozumienie

Instrukcje w bloku wykonują się kolejno. Nazwa zmiennej odczytuje wartość, a napis w cudzysłowie jest tekstem.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Najważniejsza idea

Komputer wykonuje **jednoznaczne instrukcje**. Nie rozumie naszego zamiaru tak, jak człowiek. Gdy prosimy: „oblicz sumę dwóch liczb”, musimy ustalić: skąd wziąć liczby, gdzie zapamiętać wynik i jak go pokazać.

**Algorytm** to przepis na rozwiązanie problemu, niezależny od języka programowania. **Kod źródłowy** jest zapisem tego przepisu w konkretnym języku, tutaj C++. **Program wykonywalny** powstaje po zbudowaniu kodu.

### Trzy warstwy tego samego zadania

| Warstwa | Przykład |
|---|---|
| Polecenie | Dodaj dwie liczby od użytkownika |
| Algorytm | Wczytaj `a`; wczytaj `b`; oblicz `suma = a + b`; wypisz `suma` |
| C++ | Instrukcje `std::cin`, `+`, `std::cout` |

## Pierwsza działająca aplikacja

```cpp
#include <iostream>

int main() {
    std::cout << "Witaj w StudyLab!\n";
    return 0;
}
```

Czytaj od środka: w `main()` wykonywana jest instrukcja wypisania tekstu. `return 0` oznacza prawidłowe zakończenie programu. Sam tekst `Witaj w StudyLab!` jest **napisem** (otacza go para cudzysłowów).

| Fragment | Znaczenie |
|---|---|
| `#include <iostream>` | Dostęp do strumieni konsoli |
| `int main()` | Główna funkcja programu, punkt wejścia |
| `{ }` | Wyznaczają blok instrukcji |
| `std::cout` | Standardowe wyjście, zwykle konsola |
| `<<` | Przesyła wartość do strumienia |
| `\n` | Nowa linia, a nie dwie litery |
| `;` | Kończy instrukcję |

## Prześledź program

1. Kompilator tłumaczy plik źródłowy.
2. Linker tworzy program wykonywalny.
3. Uruchamiasz program.
4. Program wypisuje komunikat i kończy się z kodem `0`.

:::tip[Po co właściwie wszystko rozpisujemy?]
Na początku nie próbuj zapamiętywać całych programów. Naucz się odpowiadać na trzy pytania: **co jest wejściem, co zmienia się w środku i co jest wyjściem?**
:::

## Spróbuj samodzielnie

Zmień napis na dowolny tekst i wypisz go w dwóch liniach. Podpowiedź: wstaw `\n` w odpowiednim miejscu albo użyj dwóch instrukcji `std::cout`.
