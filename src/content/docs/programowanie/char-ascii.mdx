# `char` i ASCII — pojedynczy znak

## Zrozum od podstaw

Znak cyfry i liczba to różne rzeczy. Napisanie 7 oznacza wartość liczbową, a apostrofy w '7' oznaczają kod znaku. char zajmuje jeden bajt C++; na typowych komputerach bajt ma 8 bitów. Podstawowe kody ASCII pozwalają porządkować cyfry i litery, ale nie opisują wszystkich języków.

Żeby zmienić znak cyfry na liczbę, odejmujemy kod '0'. Kolejne cyfry mają kolejne kody, więc odległość od zera daje ich wartość. Najpierw sprawdzamy jednak, czy znak rzeczywiście jest cyfrą.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    char c = '7';
    if (c >= '0' && c <= '9') {
        int wartosc = c - '0';
        std::cout << wartosc + 1 << '\n';
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. Apostrofy tworzą literał pojedynczego znaku.
2. Dwa porównania sprawdzają dolną i górną granicę zakresu cyfr.
3. W ASCII kod 7 to 55, a kod 0 to 48, więc różnica wynosi 7.
4. Dodajemy do liczbowej wartości 1, otrzymując 8.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
int wartosc = static_cast<int>(c);
```

Rzutowanie daje kod znaku, np. 55, a nie wartość cyfry 7. Odejmowanie zera jest poprawne po sprawdzeniu zakresu cyfr.

**Poprawiony fragment:**

```cpp
int wartosc = c - '0';
```

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Liczba czy znak?

W kodzie `'7'` (apostrofy) to **znak**, natomiast `7` to liczba całkowita. Zmienna `char` przechowuje pojedynczą jednostkę znakową o rozmiarze 1 bajta.

```cpp
char litera = 'A';
char cyfra = '7';
int liczba = 7;
std::cout << litera << ' ' << cyfra << ' ' << liczba;
```

ASCII przypisuje podstawowym znakom numery: `A → 65`, `B → 66`, `a → 97`, `0 → 48`. Kod 48 to **znak '0'**, a nie liczba całkowita zero.

## Operacje na kodach znaków

```cpp
char z = 'A';
std::cout << static_cast<int>(z) << '\n'; // 65 w ASCII
++z;
std::cout << z; // B
```

W tym przykładzie kolejne kody odpowiadają literom alfabetu. Nie używaj jednak „zwiększenia kodu znaku” jako uniwersalnego sposobu obsługi wszystkich alfabetów.

## A co z polskimi znakami?

**ASCII nie zawiera** liter `ą`, `ę`, `ł`. W UTF-8 taka litera zwykle zajmuje więcej niż jeden bajt. Dlatego `char` nie jest odpowiednikiem „jednej litery dowolnego języka”.
