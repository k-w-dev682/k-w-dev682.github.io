# Pętle zagnieżdżone

## Zrozum od podstaw

Pomyśl o kinie: wybierasz pierwszy rząd i przechodzisz przez wszystkie fotele; potem drugi rząd i znów wszystkie fotele. Pętla zewnętrzna steruje rzędami, wewnętrzna miejscami w danym rzędzie. Wewnętrzna inicjalizacja wykonuje się na nowo przy każdym wejściu do tej pętli.

Liczba operacji nie zawsze jest iloczynem dwóch stałych. Dla prostokąta 2 na 3 jest to 6, ale dla trójkąta z rosnącą długością wiersza trzeba zsumować długości kolejnych wierszy.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    for (int w = 1; w <= 2; ++w) {
        for (int k = 1; k <= 3; ++k) {
            std::cout << w << k << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. w wybiera wiersz 1 lub 2.
2. Dla każdego w k zaczyna od 1 i dochodzi do 3.
3. cout wypisuje dwie cyfry obok siebie: to etykieta pary, a nie suma.
4. Nowa linia znajduje się po pętli wewnętrznej, dlatego powstają dwa wiersze.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
std::cout << w << k << '\n';
```

Nowa linia wewnątrz wewnętrznej pętli ustawia każdą parę w osobnym wierszu. Nowy wiersz ma być dopiero po wszystkich kolumnach.

**Poprawiony fragment:**

```cpp
std::cout << w << k << ' ';
```

<details>

Dla indeksów od zera sprawdzaj w == 0, w == h - 1, k == 0 lub k == szer - 1. W tych miejscach wypisz *, w pozostałych spację; || łączy cztery możliwe brzegi.

## Zapamiętaj i sprawdź rozumienie

Wewnętrzna pętla kończy wszystkie swoje obiegi, zanim zewnętrzna przejdzie do następnego wiersza.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Jedna pętla wewnątrz drugiej

Zewnętrzna pętla wybiera **wiersz**, a wewnętrzna wykonuje wszystkie kroki potrzebne do jego narysowania. Tak powstają tekstowe prostokąty i trójkąty, o które pytają zadania z pierwszego skryptu.

```cpp
#include <iostream>
int main() {
    for (int w = 0; w < 3; ++w) {
        for (int k = 0; k < 5; ++k) {
            std::cout << '*';
        }
        std::cout << '\n';
    }
}
```

Wynik:

```text
*****
*****
*****
```

## Zrozum pętle

| `w` | Wartości `k` | Liczba gwiazdek |
|---:|---|---:|
| 0 | 0,1,2,3,4 | 5 |
| 1 | 0,1,2,3,4 | 5 |
| 2 | 0,1,2,3,4 | 5 |

Razem wykonano `3 × 5 = 15` operacji wypisywania gwiazdki. Każde `\n` występuje dopiero po **zakończeniu** pętli wewnętrznej.

## Trójkąt zamiast prostokąta

Wewnętrzny warunek zmień na `k <= w`. Dla `w=0` wypiszesz jedną gwiazdkę, dla `w=1` dwie, dla `w=2` trzy.

## Zadanie

Zaprojektuj program rysujący pusty prostokąt, w którym tylko brzegi są gwiazdkami, a środek spacjami. Warunek brzegu: `w == 0 || w == h-1 || k == 0 || k == szer-1`.
