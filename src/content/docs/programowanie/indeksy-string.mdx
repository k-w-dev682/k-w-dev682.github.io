# Indeksowanie napisu — pierwszy znak ma numer 0

## Zrozum od podstaw

Indeks to numer pozycji od zera. Dla KOT indeksy 0, 1 i 2 wybierają K, O oraz T. Rozmiar wynosi 3, ale indeks ostatniego elementu to 2. **Zakres** elementów tekstu kończy się przed size(). Pusty napis nie ma pierwszego ani ostatniego znaku treści.

Metoda at sprawdza zakres i zgłasza wyjątek, gdy nie ma wskazanego elementu. Operator [] nie daje takiej kontroli. W C++11 i nowszych odczyt s[s.size()] zwraca znak zerowy, lecz nie jest to znak treści; nie wolno zastępować go wartością niezerową. Indeks większy od size() jest niedozwolony.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "KOT";
    for (std::size_t i = 0; i < s.size(); ++i) {
        std::cout << i << ':' << s[i] << '\n';
    }
    for (std::size_t i = s.size(); i > 0; --i) {
        std::cout << s[i - 1];
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. size_t to typ bez znaku używany dla rozmiarów; tutaj licznik nie potrzebuje wartości ujemnych.
2. Pierwsza pętla wybiera 0, 1, 2 i wypisuje odpowiednie znaki.
3. Druga startuje od rozmiaru 3, ale odczytuje i − 1, czyli najpierw 2.
4. Warunek i > 0 sprawdzamy przed odejmowaniem 1, dlatego pusty napis jest bezpieczny.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
for (std::size_t i = s.size() - 1; i >= 0; --i) std::cout << s[i];
```

Typ bez znaku nigdy nie jest ujemny. Warunek >= 0 zawsze jest prawdziwy, a odejmowanie od zera zawija wartość.

**Poprawiony fragment:**

```cpp
for (std::size_t i = s.size(); i > 0; --i) std::cout << s[i - 1];
```

## Zapamiętaj i sprawdź rozumienie

Dla znaków treści używaj i &lt; size(). Nie buduj malejącej pętli size_t z warunkiem i >= 0.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Każdy element ma pozycję

W C++ numerowanie pozycji zaczyna się od **zera**.

```text
napis:  K  O  T  E  K
indeks: 0  1  2  3  4
```

```cpp
std::string napis = "KOTEK";
std::cout << napis[0]; // K
std::cout << napis[2]; // T
```

## Dlaczego nie `napis[5]`?

Dla pięciu elementów poprawne indeksy to 0–4. Indeks większy od `size()` jest niedozwolony. Odczyt `napis[5]` dla długości 5 w C++11 i nowszych daje końcowy znak zerowy, ale nie jest to znak treści. Nie wolno zastąpić go wartością niezerową. Metoda `at()` wykonuje kontrolę granic i zgłasza wyjątek `std::out_of_range`.

## Pętla po wszystkich pozycjach

```cpp
for (std::size_t i = 0; i < napis.size(); ++i) {
    std::cout << i << ": " << napis[i] << '\n';
}
```

Wybieramy `std::size_t`, bo taki typ zwykle zwraca `size()`. W materiałach możesz zobaczyć `int i`; dla krótkich napisów często działa, ale porównywanie różnych typów może generować ostrzeżenia.

## Zadanie

Wypisz znaki napisu od końca, nie używając odwracania bibliotecznego. Pomyśl, jak uniknąć zejścia poniżej zera przy pustym napisie.
