# Zapis pozycyjny i potęgi podstawy

## Zrozum od podstaw

Pozycja cyfry określa jej wagę. W 205 cyfra 2 oznacza dwie setki, a 5 pięć jedności. W systemie dwójkowym każda kolejna pozycja w lewo ma wagę dwa razy większą: 1, 2, 4, 8. **Bit** jest cyfrą 0 albo 1.

W kodzie C++ prefiks 0b oznacza literał binarny. Sam zapis binarny nie tworzy innego rodzaju liczby: 0b1101 i 13 mogą być tą samą wartością typu int. std::cout domyślnie wypisze int dziesiętnie.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    int liczba = 0b1101;
    int rozklad = 1 * 8 + 1 * 4 + 0 * 2 + 1 * 1;
    std::cout << liczba << ' ' << rozklad << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. 0b1101 odczytujemy jako sumę wag pozycji z jedynkami.
2. Mnożenie przez 0 usuwa wagę 2, pozostałe dają 8 + 4 + 1.
3. Obie zmienne przechowują 13; zapis źródłowy nie zmienia tej wartości.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
int liczba = 1101;
```

Bez prefiksu jest to tysiąc sto jeden w systemie dziesiętnym. Prefiks zmienia interpretację cyfr w źródle.

**Poprawiony fragment:**

```cpp
int liczba = 0b1101;
```

## Zapamiętaj i sprawdź rozumienie

Zaczynaj wagi od prawej: 1, 2, 4, 8. Liczba bitów opisuje ilość informacji, nie liczbę cyfr dziesiętnych.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Rozkład liczby na cyfry

W systemie dziesiętnym liczba `347` oznacza `3·100 + 4·10 + 7·1`. W binarnym każdy bit ma wagę **potęgi liczby 2**.

```text
bit:       1   0   1   1
waga:      8   4   2   1
składnik:  8 + 0 + 2 + 1 = 11
```

Zapisujemy to formalnie: `1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 11₁₀`.

## A co z ułamkami?

Za przecinkiem pojawiają się potęgi **ujemne**: `2⁻¹ = 1/2`, `2⁻² = 1/4`, `2⁻³ = 1/8`.

| Zapis binarny | Obliczenie | Dziesiętnie |
|---|---|---:|
| `0.1₂` | 1/2 | 0.5 |
| `0.01₂` | 1/4 | 0.25 |
| `0.11₂` | 1/2 + 1/4 | 0.75 |
| `0.101₂` | 1/2 + 1/8 | 0.625 |

## Dlaczego to ważne?

Pozwala wyjaśnić, dlaczego `0.5` da się zapisać dokładnie w typowym formacie binarnym, a `0.1` — nie.

## Spróbuj sam

Przelicz `1101₂` na dziesiętny. Podstaw: `1·8 + 1·4 + 0·2 + 1·1 = 13`.
