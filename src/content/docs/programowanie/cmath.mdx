# Biblioteka `<cmath>` i funkcje matematyczne

## Zrozum od podstaw

Biblioteka matematyczna dostarcza gotowe funkcje. **Argument** to wartość przekazana funkcji, a **wynik zwracany** może trafić do zmiennej lub kolejnego działania. Wywołanie sqrt(25.0) nie zmienia 25.0; oblicza nową wartość 5.

Zwracaj uwagę na dziedzinę: sqrt w obliczeniach rzeczywistych wymaga argumentu nieujemnego. floor idzie w kierunku minus nieskończoności, ceil w kierunku plus nieskończoności. Nie są tym samym co obcinanie w kierunku zera.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <cmath>

int main() {
    double x = -2.4;
    std::cout << std::floor(x) << ' ' << std::ceil(x) << '\n';
    double a = 3.0, b = 4.0;
    double przekatna = std::sqrt(a * a + b * b);
    std::cout << przekatna << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. x zawiera −2.4.
2. floor daje −3, ceil daje −2; na osi −3 leży niżej niż −2.4.
3. a i b są długościami przyprostokątnych.
4. Najpierw liczymy 9 + 16, potem sqrt(25) daje 5. Nawiasy obejmują całe wyrażenie pod pierwiastkiem.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
double pole = 3.14 * r ^ 2;
```

^ nie oznacza potęgi i nie działa na double. Dwa czynniki r wyrażają kwadrat promienia.

**Poprawiony fragment:**

```cpp
double pole = 3.141592653589793 * r * r;
```

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Nie wszystko trzeba programować od zera

W skrypcie znajdziesz m.in. `sqrt`, `pow`, `floor`, `ceil`, `abs` i `exp`. W C++ funkcje matematyczne znajdziesz zwykle w `<cmath>`.

```cpp
#include <cmath>
#include <iostream>
int main() {
    double x = 2.7;
    std::cout << std::floor(x) << '\n'; // 2
    std::cout << std::ceil(x) << '\n';  // 3
    std::cout << std::sqrt(25.0) << '\n'; // 5
    std::cout << std::pow(2.0, 3.0) << '\n'; // 8
}
```

| Funkcja | Co robi? |
|---|---|
| `std::sqrt(x)` | Pierwiastek kwadratowy |
| `std::pow(x,n)` | Potęga |
| `std::floor(x)` | Zaokrąglenie w dół, do liczby całkowitej jako wartość rzeczywista |
| `std::ceil(x)` | Zaokrąglenie w górę |
| `std::abs(x)` | Wartość bezwzględna |
| `std::exp(x)` | Wartość `e` do potęgi `x` |

## Przykład z geometrii

Dla okręgu o promieniu `r`, **pole** obliczysz ze wzoru `P = πr²`, a **obwód** ze wzoru `O = 2πr`.

```cpp
#include <numbers>
double pole = std::numbers::pi * r * r; // C++20
```

`r` oznacza promień, `π` to stała pi; jeśli korzystasz ze starszego standardu C++, zamiast `std::numbers::pi` użyj własnej stałej np. `constexpr double pi = 3.141592653589793;`.

## Zadanie

Oblicz pole koła dla `r=3`. Podstawienie: `P = π · 3 · 3 = 9π ≈ 28.2743`.
