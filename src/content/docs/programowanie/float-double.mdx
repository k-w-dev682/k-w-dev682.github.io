# `float`, `double` i liczby rzeczywiste

## Zrozum od podstaw

Wyobraź sobie linijkę z ograniczoną liczbą kresek. Wynik pomiaru pomiędzy kreskami trzeba przybliżyć. Typy float i double też mają ograniczony zbiór wartości, choć odstępy między nimi zależą od wielkości liczby. double zwykle ma więcej bitów precyzji niż float, lecz nadal nie przechowuje każdej liczby rzeczywistej dokładnie.

**Cyfry znaczące** opisują cały zapis liczby, nie tylko część po kropce. **Literał** to wartość zapisana bezpośrednio w kodzie. Zapis 0.1 ma typ double, a 0.1f typ float.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <iomanip>

int main() {
    float a = 0.5f;
    double b = 0.1;
    std::cout << std::setprecision(17) << a << '\n';
    std::cout << b << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. f na końcu 0.5f wybiera float. Połówka ma skończony zapis binarny.
2. 0.1 jest literałem double, zwykle zapisanym jako bliskie przybliżenie.
3. setprecision z nagłówka iomanip zwiększa liczbę pokazywanych cyfr; nie poprawia dokładności samej zmiennej.
4. W typowym IEEE binary64 zobaczysz 0.10000000000000001 dla b.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
int x = 2.75;
```

int odrzuci część ułamkową, jeśli konwersja mieści się w zakresie. double zachowa tutaj dokładne 2.75 = 2 + 1/2 + 1/4.

**Poprawiony fragment:**

```cpp
double x = 2.75;
```

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Typ całkowity to nie wszystko

`int` nie przechowa dokładnie liczby `3.14`. Do przybliżeń liczb rzeczywistych w C++ używamy najczęściej `float` i `double`. To typy **zmiennoprzecinkowe**, a nie „liczby z dowolną dokładnością”.

| Typ | Zwykły rozmiar | Typowa precyzja |
|---|---:|---|
| `float` | 4 bajty | zwykle 6 gwarantowanych cyfr dziesiętnych; do 9 do odtworzenia wartości z wydruku |
| `double` | 8 bajtów | zwykle 15 gwarantowanych cyfr dziesiętnych; do 17 do odtworzenia wartości z wydruku |
| `long double` | zależny od systemu | zależna od implementacji |

Nie myl **cyfr znaczących** z liczbą cyfr *po przecinku*. To nie jest to samo! Liczba `123456.7` ma siedem cyfr znaczących, mimo że po przecinku jest tylko jedna.

```cpp
#include <iostream>
int main() {
    float a = 0.1f;
    double b = 0.1;
    std::cout << a << '\n';
    std::cout << b << '\n';
}
```

Sufiks `f` w `0.1f` oznacza literał typu `float`; bez niego `0.1` ma zwykle typ `double`.

## Co znaczy „przybliżenie”?

Pamięć komputera ma ograniczoną liczbę bitów. Większość ułamków dziesiętnych nie ma skończonego rozwinięcia binarnego, więc zapisuje się **najbliższą reprezentowalną wartość**.

## Co sprawdzamy praktycznie?

Czy obliczenie wymaga tylko ogólnego przybliżenia, czy potrzebujemy bardzo małych błędów? Do obliczeń w typowych zadaniach wybieraj `double`, o ile nie istnieje konkretny powód, by użyć `float`.
