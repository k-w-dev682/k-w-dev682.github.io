# Wejście `cin` i wyjście `cout`

## Zrozum od podstaw

Strumień to uporządkowana kolejka danych. `std::cin` pobiera dane z wejścia, a `std::cout` przekazuje je na wyjście. Zwykle są to klawiatura i konsola, ale strumienie mogą być przekierowane. Dwa operatory `>>` nie oznaczają dwóch osobnych uruchomień: najpierw czytasz pierwszą liczbę, potem następną.

W przykładzie używamy dodatkowo `if`, czyli decyzji, oraz `!`, czyli zaprzeczenia. Odczyt jako warunek mówi, czy udało się pobrać oba składniki. Dzięki temu obliczenie nie ruszy po wpisaniu tekstu zamiast liczby.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    int a = 0, b = 0;
    if (!(std::cin >> a >> b)) {
        std::cout << "Bledne dane\n";
        return 1;
    }
    std::cout << "Suma: " << a + b << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. Deklaracja tworzy dwie zmienne i nadaje obu wartość 0. Przecinek oddziela deklaratory.
2. Nawiasy grupują odczyt; ! odwraca powodzenie: wejdź do bloku, jeśli odczyt się nie udał.
3. `return 1` kończy main wcześniej i sygnalizuje niepowodzenie.
4. Dopiero po udanym odczycie wypisujemy sumę. Tekst Suma: jest etykietą, nie częścią działania.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
std::cout << a << b;
```

Dla 3 i 5 pierwsza wersja skleja wypisywane wartości w 35. Operator + wykonuje dodawanie przed wysłaniem wyniku.

**Poprawiony fragment:**

```cpp
std::cout << a + b;
```

## Zapamiętaj i sprawdź rozumienie

Kierunki są różne: cin >> zmienna, cout &lt;&lt; wartość. Sprawdzaj, czy odczyt się udał.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Komunikacja z użytkownikiem

Program potrzebuje danych. Skrypt zaczyna od liczb całkowitych, więc użyjemy `int`. Standardowo do wejścia i wyjścia tekstowego służą strumienie z `<iostream>`.

```cpp
#include <iostream>
int main() {
    int a = 0;
    int b = 0;
    std::cout << "Podaj dwie liczby: ";
    std::cin >> a >> b;
    std::cout << "Suma = " << a + b << '\n';
}
```

### Jak czytać znaki `>>` i `<<`?

- `std::cin >> a` — wczytaj wartość ze strumienia do zmiennej `a`.
- `std::cout << a` — przekaż wartość `a` do strumienia wyjściowego.
- `std::cout << "Suma = " << wynik` — łączy wypisywanie kilku elementów, ale **nie dodaje** ich matematycznie.

## Przykład krok po kroku

Dla wejścia `3 5`: `a` otrzymuje 3, `b` otrzymuje 5, `a+b` daje 8, więc pojawi się `Suma = 8`.

:::caution[Co się stanie, gdy wpiszesz literę?]
Wczytanie litery do `int` może nie powieść się. W tym podstawowym przykładzie zakładamy prawidłowe dane; o sprawdzaniu wejścia dowiesz się później.
:::
