# Szyfr Cezara i metoda płotu

## Zrozum od podstaw

Cezar zmienia znaki, a płot zmienia ich kolejność. W Cezarze traktujemy alfabet jak tarczę: po z wracamy do a. Pozycje małych liter ASCII numerujemy od 0 do 25. Reszta modulo 26 pozwala zawinąć wynik.

Przesunięcie może być ujemne. W C++ reszta dla liczby ujemnej może być ujemna, dlatego normalizujemy przesunięcie dwoma operacjami modulo. Te algorytmy są ćwiczeniem z tekstu i indeksowania, nie ochroną prawdziwych sekretów.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    char c = 'z';
    int przesuniecie = 3;
    int p = ((przesuniecie % 26) + 26) % 26;
    if (c >= 'a' && c <= 'z') {
        int pozycja = c - 'a';
        char wynik = static_cast<char>('a' + (pozycja + p) % 26);
        std::cout << wynik;
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. c to znak z, a przesunięcie to liczba kroków na tarczy.
2. Normalizacja daje p od 0 do 25. Dla 3 pozostaje 3.
3. Znak z ma pozycję 25 w tym alfabecie ASCII.
4. 25 + 3 daje 28, a 28 % 26 daje 2. Pozycja 2 oznacza c.
5. static_cast&lt;char> zamienia obliczony kod z powrotem na typ znakowy.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
char wynik = static_cast<char>(c + przesuniecie);
```

Samo dodawanie kodów wychodzi poza zakres alfabetu. Po normalizacji p i sprawdzeniu małej litery modulo utrzymuje pozycję od 0 do 25.

**Poprawiony fragment:**

```cpp
char wynik = static_cast<char>('a' + (c - 'a' + p) % 26);
```

## Zapamiętaj i sprawdź rozumienie

Cezar przesuwa pozycję w alfabecie, płot przestawia pozycje w napisie. Zawsze ustal obsługiwany alfabet.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Szyfr Cezara — zasada

Przesuwamy litery w alfabecie o pewną liczbę pozycji. Dla przesunięcia 3: `A → D`, `X → A`. Musimy **zawijać się** na początku alfabetu.

```cpp
#include <string>
char szyfruj(char c, int przesuniecie) {
    if (c < 'a' || c > 'z') return c;
    int p = ((przesuniecie % 26) + 26) % 26;
    return static_cast<char>('a' + (c - 'a' + p) % 26);
}
```

W tym przykładzie szyfrujemy **tylko małe litery ASCII**. Ujemne przesunięcie także zadziała, bo normalizujemy je modulo 26.

## Szyfr płotu o dwóch rzędach

Przepis z materiału: znak pierwszy, trzeci, piąty itd. trafiają do górnego rzędu; drugi, czwarty itd. do dolnego. Na końcu zapisujemy kolejno górny i dolny rząd.

Przykład dla napisu `KOTEK`:

```text
GÓRNY: K T K
DOLNY:  O E
WYNIK: KTKOE
```

```cpp
std::string koduj(const std::string& s) {
    std::string wynik;
    for (std::size_t i = 0; i < s.size(); i += 2) wynik += s[i];
    for (std::size_t i = 1; i < s.size(); i += 2) wynik += s[i];
    return wynik;
}
```

## Co warto zapamiętać?

To przykłady **algorytmów przekształcania tekstu**, a nie bezpiecznego szyfrowania współczesnych danych. Żaden z tych szyfrów nie chroni prawdziwych sekretów.
