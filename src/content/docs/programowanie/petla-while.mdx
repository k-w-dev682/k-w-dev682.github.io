# Pętla `while` — powtarzaj, aż warunek przestanie być prawdziwy

## Zrozum od podstaw

Pętla `while` działa jak pytanie „czy jeszcze mam coś do zrobienia?”. Najpierw sprawdza warunek; dopiero odpowiedź TAK pozwala wejść do środka. Po ciele wraca do tego samego pytania. **Iteracja** to jeden przebieg ciała, nie samo sprawdzenie warunku.

Przed uruchomieniem wskaż trzy rzeczy: stan początkowy, warunek kontynuowania i instrukcję, która przybliża do końca. Pętla może wykonać zero iteracji, jeśli warunek jest fałszywy już na starcie.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    int i = 3;
    int suma = 0;
    while (i > 0) {
        suma += i;
        --i;
    }
    std::cout << suma << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. i zaczyna od 3, a akumulator suma od neutralnego dla dodawania zera.
2. while sprawdza i > 0 przed każdym wejściem.
3. += dodaje bieżące i do dotychczasowej sumy.
4. --i zmniejsza licznik o 1. Przy i = 0 warunek przestaje być prawdziwy.
5. Wypisanie jest poza klamrami pętli, więc występuje raz.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
while (i > 0) { suma += i; }
```

Bez zmiany i warunek pozostaje prawdziwy; suma nie jest licznikiem sterującym tą pętlą. Długie dodawanie może też przekroczyć zakres int.

**Poprawiony fragment:**

```cpp
while (i > 0) { suma += i; --i; }
```

## Zapamiętaj i sprawdź rozumienie

Warunek mówi „kontynuuj, dopóki prawda”, a nie „zakończ, gdy prawda”. Zmiana stanu musi umożliwić zakończenie.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Jak działa `while`?

`while (warunek)` sprawdza warunek **przed każdą iteracją**. Jeśli jest prawdziwy, wykonuje blok instrukcji; jeśli fałszywy — przechodzi za pętlę.

```cpp
int i = 1;
while (i <= 4) {
    std::cout << i << ' ';
    i = i + 1;
}
// Wynik: 1 2 3 4
```

## Rozpiska instrukcja po instrukcji

| Sprawdzenie `i <= 4` | Wypisano | Zmiana `i` |
|---|---|---|
| `1 <= 4` → TAK | 1 | 2 |
| `2 <= 4` → TAK | 2 | 3 |
| `3 <= 4` → TAK | 3 | 4 |
| `4 <= 4` → TAK | 4 | 5 |
| `5 <= 4` → NIE | nic | koniec |

**Iteracja** to jedno wykonanie ciała pętli. Nie myl liczby sprawdzeń warunku z liczbą iteracji — tutaj warunek sprawdzamy pięć razy, ale ciało wykonujemy cztery razy.

## Błąd: pętla nieskończona

```cpp
int i = 1;
while (i <= 4) {
    std::cout << i; // BRAK: i++
}
```

Warunek pozostanie prawdziwy, bo `i` w ogóle się nie zmienia. Nieskończonej pętli można również używać celowo, ale trzeba przewidzieć sposób zakończenia.

## Ćwiczenie

Zmień warunek na `i < 4`. Co wypisze? **1 2 3**, bo dla `i == 4` warunek jest już fałszywy.
