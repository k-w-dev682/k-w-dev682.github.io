# Konwersja napisu na liczbę

## Zrozum od podstaw

Parsowanie oznacza odczyt znaczenia tekstu według reguł, np. rozpoznanie liczby w napisie. stoi zamienia początek napisu na int, ale sam sukces nie znaczy jeszcze, że wykorzystano cały tekst. Dla 12x początek 12 jest liczbą, a x pozostaje dopiskiem.

Wyjątek sygnalizuje sytuację, w której funkcja nie może zwrócić zwykłego wyniku. try obejmuje próbę, catch obsługuje dany rodzaj problemu. Zapis &koniec przekazuje adres zmiennej, aby stoi mogło zapisać tam pozycję końca rozpoznanej części.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <string>
#include <stdexcept>

int main() {
    std::string s = "12x";
    try {
        std::size_t koniec = 0;
        int x = std::stoi(s, &koniec);
        if (koniec == s.size()) std::cout << x;
        else std::cout << "Dopisek od pozycji " << koniec;
    } catch (const std::invalid_argument&) {
        std::cout << "Brak liczby";
    } catch (const std::out_of_range&) {
        std::cout << "Poza zakresem int";
    }
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. string zawiera bajty 1, 2, x, nie gotową liczbę.
2. stoi rozpoznaje 12 i zapisuje 2 do koniec.
3. Rozmiar wynosi 3, więc wykryto dopisek zaczynający się pod indeksem 2.
4. const i & w catch pozwalają odebrać wyjątek przez referencję bez jego kopiowania; nie modyfikujemy go.
5. stdexcept udostępnia nazwy wyjątków użyte w tym przykładzie.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
int x = std::stoi(s); // uznajemy cały napis za poprawny
```

Bez kontroli pozycji końca akceptujesz częściowy odczyt. Obsługę wyjątków zachowaj jak w pełnym przykładzie.

**Poprawiony fragment:**

```cpp
std::size_t p = 0;
int x = std::stoi(s, &p);
if (p != s.size()) std::cout << "Dopisek";
```

Rozróżniaj brak liczby, przekroczenie zakresu i niewykorzystaną końcówkę. Nie ignoruj wyjątków.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Tekst "123" to nie liczba 123

Możemy wczytać napis cyfr, ale zanim wykonamy na nim działania arytmetyczne, musimy dokonać konwersji. W starszym materiale pojawia się m.in. `atoi()` i strumienie tekstowe. We współczesnym C++ dostępne są `std::stoi` i `std::stod`.

```cpp
#include <string>
#include <iostream>
int main() {
    std::string tekst = "123";
    int liczba = std::stoi(tekst);
    std::cout << liczba * 3; // 369
}
```

## Jakie błędy mogą wystąpić?

- `std::invalid_argument`, gdy nie da się wczytać liczby.
- `std::out_of_range`, gdy wartość nie mieści się w typie.
- Częściowe parsowanie: `stoi("123abc")` może zaakceptować początkowe cyfry, jeśli nie zweryfikujesz całego napisu.

```cpp
std::size_t koniec = 0;
int x = std::stoi(tekst, &koniec);
if (koniec != tekst.size()) {
    std::cout << "Tekst zawiera dodatkowe znaki";
}
```

W praktyce obsłuż również wyjątki (`try` / `catch`) lub wybierz niezgłaszającą wyjątków konwersję, np. `std::from_chars` dla odpowiednich typów.

## Zadanie

Wczytaj napis i sprawdź, czy jest poprawną liczbą całkowitą bez dopisków. Przetestuj: `"17"`, `"-8"`, `"12x"`, `"abc"`.
