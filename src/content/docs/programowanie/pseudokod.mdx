# Pseudokod i schematy blokowe

## Najpierw pomysł, potem składnia

W skrypcie proste zadania — suma dwóch liczb i sumowanie ciągu — pokazano najpierw za pomocą **pseudokodu** i schematów blokowych. To dobry nawyk: rozwiązanie możesz sprawdzić na papierze, zanim przełożysz je na C++.

### Algorytm sumowania dwóch liczb

1. START.
2. Wczytaj `a`, `b`.
3. Oblicz `suma = a + b`.
4. Wypisz `suma`.
5. STOP.

```text
   ┌───────────┐
   │   START   │
   └─────┬─────┘
         ↓
   ┌───────────┐
   │  a oraz b │  ← dane wejściowe
   └─────┬─────┘
         ↓
   ┌───────────┐
   │ suma=a+b  │  ← obliczenie
   └─────┬─────┘
         ↓
   ┌───────────┐
   │ wypisz    │  ← wynik
   └─────┬─────┘
         ↓
       STOP
```

## Najważniejsze kształty

| Kształt | Znaczenie |
|---|---|
| Owal | Początek i koniec |
| Prostokąt | Obliczenie lub przetworzenie danych |
| Równoległobok | Wczytaj lub wypisz dane |
| Romb | Warunek: tak/nie |
| Strzałka | Kolejność przepływu |

## Kiedy schemat jest naprawdę pomocny?

Najbardziej przy rozgałęzieniach i pętlach. Jeśli nie umiesz narysować, **kiedy** pętla się zatrzyma, prawdopodobnie nie rozumiesz jeszcze jej warunku.

## Ćwiczenie

Zapisz pseudokod programu wypisującego większą z dwóch liczb. Gdzie potrzebujesz rombu? Przy warunku `a > b`.
