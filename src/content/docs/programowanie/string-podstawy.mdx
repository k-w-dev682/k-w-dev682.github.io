# `std::string` — napisy

## Napis to sekwencja znaków

W C++ `std::string` pozwala przechowywać i modyfikować napisy. Jest wygodniejszy do pracy z tekstem niż ręcznie tworzona tablica `char`.

```cpp
#include <iostream>
#include <string>
int main() {
    std::string imie = "Ala";
    std::cout << imie << '\n';
    std::cout << imie.size() << '\n'; // 3 bajty / elementy char
}
```

`std::string` to **klasa**, która zarządza przechowywanymi elementami `char`. Możesz traktować jej zawartość jako ciąg bajtów znakowych i korzystać z metod.

## Porównanie z `char`

| `char` | `std::string` |
|---|---|
| `'A'` — pojedynczy element | `"Ala"` — napis |
| Apostrofy | Cudzysłowy |
| Zwykle 1 bajt | Długość zmienna |
| Prosty kod znaku | Łączenie, wycinanie, wyszukiwanie |

## Konkatenacja (łączenie)

```cpp
std::string a = "Ala";
std::string b = " ma kota";
std::string wynik = a + b;
// "Ala ma kota"
```

### Uwaga o UTF-8

`size()` zwraca liczbę elementów `char` (bajtów), a **nie zawsze liczbę widocznych liter**. Napis `"ą"` zapisany w UTF-8 może mieć `size() == 2`.

## Ćwiczenie

Złącz imię i nazwisko, dopisując między nimi spację. Upewnij się, że nie sklejasz słów bez odstępu.
