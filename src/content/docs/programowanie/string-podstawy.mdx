# `std::string` — napisy

## Zrozum od podstaw

std::string jest obiektem zarządzającym ciągiem elementów char. Możesz myśleć o nim jak o pasku ponumerowanych pól, który da się wydłużać. Długość może wynosić zero; pusty napis to normalna wartość.

**Metoda** to funkcja wywoływana dla obiektu, np. s.size(). Kropka wybiera metodę, a nawiasy oznaczają jej wywołanie. **Konkatenacja** oznacza połączenie napisów, bez automatycznego dodawania spacji.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string imie = "Ala";
    std::string nazwisko = "Kot";
    std::string razem = imie + " " + nazwisko;
    std::cout << razem << '\n';
    std::cout << razem.size() << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. string wymaga nagłówka string. Oba napisy zapisujemy w cudzysłowach.
2. Łączenie tworzy napis Ala Kot z jawną spacją między częściami.
3. Pierwszy cout wypisuje treść.
4. size() zwraca 7: trzy bajty imienia, spacja i trzy bajty nazwiska w tym przykładzie ASCII.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
std::string razem = "Ala" + "Kot";
```

Dwóch literałów tablicowych nie łączy się operatorem + w ten sposób. Utworzenie std::string pozwala użyć operatora łączenia.

**Poprawiony fragment:**

```cpp
std::string razem = std::string("Ala") + " " + "Kot";
```

## Zapamiętaj i sprawdź rozumienie

size() liczy elementy char, nie uniwersalne znaki widoczne. W UTF-8 litera może zajmować kilka elementów.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Napis to sekwencja znaków

W C++ `std::string` pozwala przechowywać i modyfikować napisy. Jest wygodniejszy do pracy z tekstem niż ręcznie tworzona tablica `char`.

```cpp
#include <iostream>
#include <string>
int main() {
    std::string imie = "Ala";
    std::cout << imie << '\n';
    std::cout << imie.size() << '\n'; // 3 bajty / elementy char
}
```

`std::string` to **klasa**, która zarządza przechowywanymi elementami `char`. Możesz traktować jej zawartość jako ciąg bajtów znakowych i korzystać z metod.

## Porównanie z `char`

| `char` | `std::string` |
|---|---|
| `'A'` — pojedynczy element | `"Ala"` — napis |
| Apostrofy | Cudzysłowy |
| Zwykle 1 bajt | Długość zmienna |
| Prosty kod znaku | Łączenie, wycinanie, wyszukiwanie |

## Konkatenacja (łączenie)

```cpp
std::string a = "Ala";
std::string b = " ma kota";
std::string wynik = a + b;
// "Ala ma kota"
```

### Uwaga o UTF-8

`size()` zwraca liczbę elementów `char` (bajtów), a **nie zawsze liczbę widocznych liter**. Napis `"ą"` zapisany w UTF-8 może mieć `size() == 2`.

## Ćwiczenie

Złącz imię i nazwisko, dopisując między nimi spację. Upewnij się, że nie sklejasz słów bez odstępu.
