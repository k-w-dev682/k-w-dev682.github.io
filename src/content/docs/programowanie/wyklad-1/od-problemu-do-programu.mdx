# Od problemu do programu

## Zalecana kolejność pracy

1. **Sformułuj zadanie** — opisz dokładnie, co ma zostać obliczone.
2. **Określ wejście i wyjście** — typ, zakres i jednostki danych.
3. **Ułóż algorytm** — kroki rozwiązania bez skupiania się na składni.
4. **Sprawdź na przykładach** — także na danych granicznych.
5. **Zapisz kod** — wybierz konstrukcje języka C++.
6. **Skompiluj i uruchom** — napraw błędy składni i działania.
7. **Przetestuj** — porównaj wynik programu z oczekiwanym i popraw algorytm, jeśli to konieczne.

## Przykład prowadzony: suma dodatnich liczb od 1 do n

**Wejście:** całkowite `n` z przedziału `0…10000`. **Wyjście:** suma liczb `1 + 2 + ... + n` (dla zera wynosi 0).

Pseudokod:

```text
wczytaj n
jeżeli n < 0 lub n > 10000: zgłoś błąd i zakończ
suma = 0
od i = 1 do n: suma = suma + i
wypisz suma
```

Implementacja:

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    if (!std::cin || n < 0 || n > 10000) {
        std::cout << "Niepoprawne n\n";
        return 1;
    }

    long long suma = 0;
    for (int i = 1; i <= n; ++i) {
        suma += i;
    }
    std::cout << suma << '\n';
}
```

### Śledzenie dla `n = 4`

| i | suma przed dodaniem | suma po dodaniu |
|---:|---:|---:|
| 1 | 0 | 1 |
| 2 | 1 | 3 |
| 3 | 3 | 6 |
| 4 | 6 | 10 |

Dla `n = 0` pętla nie wykona się ani razu; wynik pozostanie 0. Dla `n = -1` program nie zacznie obliczeń, tylko wypisze komunikat błędu.

### Dlaczego `long long`?

Suma może być większa niż pojedyncza dodawana wartość. Dla `n=10000` wynik wynosi 50 005 000. Typ `long long` daje bezpieczny zapas w tym zadaniu.

## Co oznacza testowanie?

Nie wystarczy jeden poprawny przykład. Wypróbuj dane **typowe** (`4`), **brzegowe** (`0`, `10000`) i **nieprawidłowe** (`-1`, `10001`, tekst). Kompilator wykrywa błędy języka, ale nie sprawdzi automatycznie, czy wybrany przez nas wzór rozwiązuje zadanie.
