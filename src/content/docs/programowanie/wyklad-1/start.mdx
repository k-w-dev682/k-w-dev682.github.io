## Trzy pojęcia, których nie należy mylić

| Pojęcie | Co oznacza | Przykład |
|---|---|---|
| **Problem** | Co trzeba osiągnąć | „Znajdź większą z dwóch liczb” |
| **Algorytm** | Jakie kroki prowadzą do wyniku | „Porównaj a i b, wybierz większą wartość” |
| **Program** | Zapis rozwiązania w konkretnym języku | Kod C++ z `if` i `std::cout` |

Przykład pełnego programu:

```cpp
#include <iostream>

int main() {
    int a = 7;
    int b = 11;
    if (a > b) {
        std::cout << a << '\n';
    } else {
        std::cout << b << '\n';
    }
}
```

Wynik: **11**. Program działa, ponieważ instrukcja `if` realizuje wcześniej ustalony algorytm.

## Co powinno zostać po wykładzie?

Powinieneś umieć wyjaśnić różnicę między algorytmem a programem, określić **dane wejściowe** i **wynik**, narysować prosty schemat blokowy, wymienić elementy komputera i opowiedzieć, co robi kompilator. Dopiero wtedy przejdź do szczegółów składni C++.
