# Palindrom i odwracanie napisu

## Zrozum od podstaw

Palindrom jest taki sam z obu stron. Zamiast tworzyć odwróconą kopię, możemy porównywać pary: pierwszy z ostatnim, drugi z przedostatnim. Pierwsza nierówna para wystarcza, aby odrzucić napis.

Umawiamy się na porównywanie dokładnych bajtów ASCII, z uwzględnieniem wielkości liter i spacji. Pusty napis i napis jednoznakowy przechodzą test: nie ma w nich żadnej sprzecznej pary. Przy UTF-8 odwracanie samych bajtów może uszkodzić litery.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "kajak";
    bool pasuje = true;
    for (std::size_t i = 0; i < s.size() / 2; ++i) {
        if (s[i] != s[s.size() - 1 - i]) {
            pasuje = false;
            break;
        }
    }
    std::cout << std::boolalpha << pasuje;
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. bool przechowuje hipotezę: do tej pory nie znaleziono różnicy.
2. size() / 2 daje 2 dla długości 5; sprawdzamy dwie pary.
3. Indeks z prawej to długość − 1 − i. Dla i = 0 otrzymujemy 4.
4. break opuszcza najbliższą pętlę po wykryciu różnicy.
5. Operator != oznacza nierówność znaków. Środkowe j nie potrzebuje pary.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
if (s[i] != s[s.size() - i]) pasuje = false;
```

Pierwszy indeks od prawej to size() − 1, nie size(). Przesunięcie o jeden wybiera niewłaściwy znak.

**Poprawiony fragment:**

```cpp
if (s[i] != s[s.size() - 1 - i]) pasuje = false;
```

Wystarczy połowa długości i jedna nierówność, by zakończyć sprawdzanie. Normalizacja tekstu jest osobnym etapem.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Co to jest palindrom?

Napis, który czytany od lewej i prawej strony jest taki sam, np. `kajak`. W najprostszej wersji zakładamy, że nie ma spacji ani różnic wielkości liter.

```cpp
#include <string>
#include <iostream>
int main() {
    std::string s;
    std::cin >> s;
    bool palindrom = true;
    for (std::size_t i = 0; i < s.size() / 2; ++i) {
        if (s[i] != s[s.size() - 1 - i]) {
            palindrom = false;
            break;
        }
    }
    std::cout << (palindrom ? "TAK" : "NIE");
}
```

## Dlaczego wystarczy połowa?

Sprawdzamy **pary**: pierwszy z ostatnim, drugi z przedostatnim itd. Jeśli wszystkie odpowiadają, nie trzeba jeszcze raz badać tych samych znaków z drugiej strony.

| `kajak` | Para | Wynik |
|---|---|---|
| i = 0 | k oraz k | równe |
| i = 1 | a oraz a | równe |
| koniec | środek `j` | bez pary |

## Wariant trudniejszy

Dla zdań trzeba zdecydować, czy ignorujemy spacje, wielkość liter i interpunkcję. Dla polskich liter sprawa wymaga świadomej obsługi Unicode.

Sprawdź słowa `kajak`, `oko`, `kot`, `abba`. Przewidź wynik zanim uruchomisz program.
