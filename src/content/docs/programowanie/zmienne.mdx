# Zmienne, inicjalizacja i `int`

## Zrozum od podstaw

Zmienna przypomina podpisaną przegródkę, ale jej typ określa dozwolone wartości i operacje. Nazwa nie jest wartością: po przypisaniu nazwa zostaje, a zawartość może się zmienić. **Deklaracja** wprowadza nazwę; **inicjalizacja** nadaje pierwszą wartość; **przypisanie** zmienia istniejącą wartość.

W `x = x + 3` najpierw odczytujesz prawą stronę. Dopiero gotowy wynik zastępuje starą zawartość x. Nie rozwiązujesz równania matematycznego. Zwykła lokalna zmienna bez inicjalizacji nie jest bezpiecznym źródłem danych.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    int x = 4;
    int kopia = x;
    x = x + 3;
    kopia *= 2;
    std::cout << x << ' ' << kopia << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. `int x = 4` tworzy liczbę całkowitą.
2. `int kopia = x` odczytuje 4 i zapisuje ją do osobnej zmiennej. Nie tworzy połączenia między nimi.
3. Prawa strona x + 3 daje 7; zastępujemy 4 przez 7.
4. `kopia *= 2` to skrót przypisania wyniku mnożenia kopia przez 2.
5. Apostrofy w ' ' oznaczają jeden znak spacji między wynikami.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
int suma;
suma += 5;
```

+= musi odczytać starą wartość. Bez inicjalizacji nie mamy ustalonej wartości do dodania.

**Poprawiony fragment:**

```cpp
int suma = 0;
suma += 5;
```

### 3. Jak zamienić x = 2 i y = 9 miejscami?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

Użyj `int temp = x; x = y; y = temp;`. temp zachowuje 2 przed nadpisaniem x; wynik to x = 9, y = 2.

</details>

## Zapamiętaj i sprawdź rozumienie

Inicjalizuj zmienne. Zwykłe przypisanie kopiuje wartość; nie wiąże na stałe dwóch nazw.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Co jest zmienną?

Zmienna ma **typ**, **nazwę** i aktualną **wartość**. Typ `int` przechowuje liczby całkowite w zakresie zależnym od implementacji (na współczesnych komputerach zwykle 32-bitowy).

```cpp
int wynik = 0;   // deklaracja i inicjalizacja
wynik = wynik + 4;
wynik = wynik + 7;
std::cout << wynik; // 11
```

`wynik = wynik + 4` nie jest równaniem. Oznacza: **odczytaj poprzedni wynik, dodaj 4, zapisz nowy wynik**.

## Śledź wartości

| Instrukcja | Przed | Po |
|---|---:|---:|
| `int wynik = 0;` | — | 0 |
| `wynik = wynik + 4;` | 0 | 4 |
| `wynik = wynik + 7;` | 4 | 11 |

### Po co `wynik = 0`?

Gdy napiszesz `int wynik;` wewnątrz funkcji, jego wartość **nie jest automatycznie zerem**. Odczytywanie niezainicjalizowanej zmiennej jest błędem. Dlatego sumowanie zaczynaj od `0`, a mnożenie wielu czynników — od `1`.

## Różne sposoby zapisu

```cpp
int x = 4;
int y{5};
int suma = x + y;
```

Warto używać nazw opisujących dane: `suma`, `licznik`, `promien`, a nie samych `a`, `b`, `c`, kiedy program robi się dłuższy.
