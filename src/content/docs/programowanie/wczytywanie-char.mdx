# Wczytywanie znaku i klawisze specjalne

## Zrozum od podstaw

Naciśnięcie klawisza i odczyt znaku ze strumienia nie są tym samym. Terminal zwykle zbiera linię i przekazuje ją po Enterze. Operator >> dla char pomija początkowe białe znaki, natomiast get odczytuje następny znak także wtedy, gdy jest spacją lub nową linią.

Jeśli chcesz liczyć wpisane litery aż do k, ustal, czy k wchodzi do wyniku i czy spacje są liczone. Poniżej pomijamy białe znaki i nie liczymy wartownika. Koniec wejścia także zatrzymuje pętlę.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    char c = '\0';
    int ile = 0;
    while (std::cin >> c && c != 'k') {
        ++ile;
    }
    std::cout << ile << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. \0 to znak o wartości zero, nie litera 0. Daje określoną wartość początkową.
2. Odczyt jest sprawdzany przed porównaniem z wartownikiem.
3. Każdy zaakceptowany znak zwiększa licznik o jeden. Ten wariant liczy też cyfry i interpunkcję.
4. Warunek c != 'k' wyklucza małe k, ale nie wielkie K.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
while (c != 'k') { ++ile; }
```

Pierwsza pętla nie czyta kolejnych znaków; druga odświeża c w każdej próbie.

**Poprawiony fragment:**

```cpp
while (std::cin >> c && c != 'k') { ++ile; }
```

## Przećwicz — od przewidywania do samodzielnej zmiany

### 1. Co dla wejścia k jako pierwszego znaku?

### 2. Jak czytać także spacje?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

Użyj `while (std::cin.get(c) && c != 'k')`. Wówczas także Enter może zwiększyć licznik, jeżeli pojawi się przed k.

</details>

### 3. Jak liczyć tylko małe litery ASCII?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

W ciele dodaj if (c >= 'a' && c &lt;= 'z') ++ile. Kategoria „znak” jest szersza niż „litera”.

</details>

## Zapamiętaj i sprawdź rozumienie

>> pomija białe znaki, get ich nie pomija. Klawisze F1–F12 nie mają jednego przenośnego kodu char.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Dwa różne problemy

1. **Wczytanie znaku z tekstu**: użytkownik wpisuje znak i potwierdza Enterem.
2. **Wykrycie naciśniętego klawisza od razu**: wymaga sposobu obsługi klawiatury zależnego od terminala lub biblioteki.

```cpp
#include <iostream>
int main() {
    char z;
    std::cout << "Podaj znak: ";
    std::cin >> z;
    std::cout << "Podano: " << z << '\n';
}
```

`std::cin >> z` pomija początkowe białe znaki i wczytuje jedną jednostkę `char`. Aby czytać także spację, możesz użyć `std::cin.get(z)`.

## `getch()` ze starego skryptu

Skrypt używa `<conio.h>` i `getch()` do przechwytywania klawiszy. To **rozszerzenie niespełniające standardu ISO C++**, dostępne w wybranych środowiskach. W nowoczesnych terminalach klawisze funkcyjne mogą być reprezentowane jako sekwencje bajtów, więc nie można przyjmować, że każdy F1 ma jeden globalnie obowiązujący kod ASCII.

| Sposób | Zaleta | Ograniczenie |
|---|---|---|
| `std::cin >> z` | Standard C++ | Zwykle czeka na Enter, pomija białe znaki |
| `std::cin.get(z)` | Czyta również spację/nową linię | Nadal zależny od trybu wejścia terminala |
| `getch()` | Natychmiastowy klawisz w wybranych środowiskach | Nieprzenośny |

Napisz program, który wczytuje znaki aż do `'k'` i liczy, ile liter wpisano przed znacznikiem. Wariant zaawansowany: rozróżnij wielkie litery ASCII.
