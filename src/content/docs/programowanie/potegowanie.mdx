# Potęgowanie przez pętlę

## Zrozum od podstaw

Potęga to powtarzane mnożenie: 2 do potęgi 3 to trzy czynniki równe 2. Liczba 3 mówi o liczbie mnożeń w naszym algorytmie, a nie o tym, ile dodać do 2. Wynik zaczyna od 1, bo 1 nie zmienia iloczynu.

Wykładnik zerowy oznacza brak mnożeń. Dla niezerowej podstawy pozostaje 1. Wykładnik ujemny oznacza odwrotność odpowiedniej potęgi dodatniej. Przypadki z zerową podstawą wymagają osobnej decyzji; w kursie odrzucamy 0 do potęgi 0 i potęgi ujemne zera.

## Przykład prowadzony — kompletny program

Skopiuj ten przykład do osobnego pliku `.cpp`. W kursie używamy C++20. Każdy pełny program ma jedno `main`.

```cpp
#include <iostream>

int main() {
    double podstawa = 2.0;
    int wykladnik = 3;
    double wynik = 1.0;
    for (int i = 0; i < wykladnik; ++i) wynik *= podstawa;
    std::cout << wynik << '\n';
    return 0;
}
```

### Czytamy kod po kolei

`#include` udostępnia deklaracje z podanego nagłówka; `std::` wskazuje nazwę z biblioteki standardowej. Klamry wyznaczają blok, a średnik kończy instrukcję. `main` jest punktem wejścia; `return 0` oznacza poprawne zakończenie.

1. double pozwala użyć także podstawy z częścią ułamkową.
2. wykladnik określa trzy powtórzenia.
3. wynik = 1.0 jest elementem neutralnym mnożenia.
4. *= mnoży poprzedni wynik przez podstawę; kolejne wyniki to 2, 4, 8.

### Znajdź i napraw błąd

**Błędny fragment — nie kopiuj go jako rozwiązania:**

```cpp
double wynik = 0.0;
```

Mnożenie zera przez dowolną skończoną podstawę dalej daje zero. Start od zera niszczy cały algorytm.

**Poprawiony fragment:**

```cpp
double wynik = 1.0;
```

## Przećwicz — od przewidywania do samodzielnej zmiany

### 1. Co dla podstawy 3 i wykładnika 2?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

</details>

### 2. Co dla wykładnika 0 i podstawy 7?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

1, bo pętla nie wykona żadnego mnożenia.

</details>

### 3. Jak uzyskać 2 do potęgi −3?

<details>
<summary>Sprawdź odpowiedź i uzasadnienie</summary>

Najpierw oblicz 8 dla trzech mnożeń, potem 1.0 / 8 = 0.125. Dzielenie 1 / 8 w typie int dałoby 0.

</details>

## Zapamiętaj i sprawdź rozumienie

Powtarzane mnożenie startuje od 1. Operator ^ w C++ jest XOR-em bitowym, a nie potęgowaniem.

**Powtórka bez patrzenia:** wyjaśnij, dlaczego poprawka w sekcji „Znajdź i napraw błąd” działa. Następnie zmień dane w przykładzie prowadzonym i odtwórz jego stany przed uruchomieniem. Wróć do trzech odpowiedzi powyżej, aby porównać swoje uzasadnienie.

## Rozwinięcie tematu i dotychczasowe ćwiczenia

## Polecenie ze skryptu

Dla liczby rzeczywistej `x` i całkowitego wykładnika `n` oblicz `x` do potęgi `n`. To zadanie rozwija poprzednie mnożenie bez operatora `*`: zamiast powtarzać dodawanie, powtarzamy mnożenie.

Matematycznie: `x³ = x · x · x`, natomiast `x⁰ = 1` dla `x ≠ 0` i `x⁻² = 1/(x²)`.

```cpp
#include <iostream>
int main() {
    double x;
    int n;
    std::cin >> x >> n;
    if (x == 0 && n <= 0) {
        std::cout << "Nieokreslony przypadek\n";
        return 1;
    }
    double wynik = 1.0;
    long long e = n;
    if (e < 0) e = -e;
    for (long long i = 0; i < e; ++i) wynik *= x;
    if (n < 0) wynik = 1.0 / wynik;
    std::cout << wynik << '\n';
}
```

**Dlaczego wynik zaczyna się od 1?** Mnożenie przez 1 nie zmienia wartości. Gdyby zacząć od 0, każdy wynik pozostałby zerem.

## Śledzenie `x=2`, `n=3`

| Krok | Mnożenie | `wynik` |
|---:|---|---:|
| Start | — | 1 |
| 1 | 1 × 2 | 2 |
| 2 | 2 × 2 | 4 |
| 3 | 4 × 2 | 8 |

Uwaga: to algorytm dydaktyczny; przy ogromnych wykładnikach wynik może wyjść poza zakres `double`. Dla praktycznych obliczeń istnieje `std::pow` i szybszy algorytm potęgowania przez podnoszenie do kwadratu.

## Ćwiczenie

Oblicz krok po kroku `x=2, n=-3`. Po trzech mnożeniach uzyskujemy 8; ponieważ wykładnik jest ujemny, wynikiem jest `1/8 = 0.125`.
