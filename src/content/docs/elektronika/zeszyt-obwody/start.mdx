# Zeszyt — elementy i obwody elektryczne

**Materiały dydaktyczne z Podstaw elektroniki.** Ten dział uzupełnia dotychczasowy kurs; nie zmienia istniejących lekcji, książek ani prywatnych notatek. Obejmuje **10 zdjęć notatek** i dodatkowe objaśnienia na podstawie załączonego podręcznika *Elementy i układy elektroniczne w pytaniach i odpowiedziach*.

:::note[Co oznaczają trzy kropki?]
W notatkach `...` oznacza **niedokończony fragment**, a nie koniec tematu. Uzupełniono podstawową teorię w oparciu o podręcznik i standardowe zależności elektrotechniczne. Ponieważ książka **nie jest transkrypcją wykładu**, uzupełnienie może nie odpowiadać dosłownemu dalszemu ciągowi wypowiedzi prowadzącego. Pytania do sprawdzenia są w [Rejestrze niepewności](../niepewnosci/).
:::

## Jak rozumieć źródła?

- **Zeszyt** — temat i kolejność pojęć, także skróty i niedokończone hasła (zdjęcia 1–10).
- **Podręcznik** — uzupełnienie pojęć dotyczących obwodów, elementów biernych, rezystorów, kondensatorów i cewek; przede wszystkim części o teorii obwodów i elementach biernych.
- **Wyjaśnienie StudyLab** — niezależne, proste przykłady, dodatkowe zastrzeżenia, zadania i odtworzone schematy. **Nie są dosłownymi cytatami z książki.**

## Najważniejsze pary, których nie należy mylić

| Wielkość | Symbol | Jednostka | O co pytamy? |
|---|---|---|---|
| Ładunek | `q`, `Q` | C | Ile ładunku? |
| Natężenie prądu | `I`, `i(t)` | A | Jak szybko przepływa ładunek? |
| Napięcie | `U`, `u(t)` | V | Jaka jest różnica potencjałów? |
| Rezystancja | `R` | Ω | Jak silny jest opór elementu? |
| Moc | `P`, `p(t)` | W | Jak szybko przekazywana jest energia? |
| Energia | `W`, `E` | J | Ile energii przekazano lub zgromadzono? |
| Indukcyjność | `L` | H | Jak bardzo cewka wiąże zmiany prądu ze strumieniem? |
| Pojemność | `C` | F | Jak dużo ładunku gromadzi się przy danym napięciu? |

:::tip[Jak liczyć?]
Zawsze wypisz **dane → szukane → wzór → podstawienie w jednostkach SI → wynik z jednostką → krótki test sensowności**.
:::
