# Moment siły i równowaga obrotowa

Moment siły określa zdolność siły do obracania ciała względem osi lub punktu.

<Eq tex={String.raw`\vec\tau=\vec r\times\vec F`} display />
<Eq tex={String.raw`|\tau|=rF\sin\theta`} display />

### Przykład: klucz do śruby

Długość klucza r = 0,25 m, siła F = 40 N jest prostopadła do ramienia.

Moment siły: τ = 0,25·40·sin(90°) = **10 N·m**.

Jednostka N·m jest taka sama wymiarowo jak dżul, ale moment siły i energia opisują inne wielkości.

Dla obrotu wokół nieruchomej osi i stałego momentu bezwładności zachodzi relacja τ = I·alfa, gdzie alfa jest przyspieszeniem kątowym. To **uzupełnienie dydaktyczne**, nie dosłowny zapis z zeszytu.
