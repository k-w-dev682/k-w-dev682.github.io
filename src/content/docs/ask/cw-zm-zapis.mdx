# Ćwiczenia ZM: zapis liczb dodatnich i ujemnych

Oryginalne zadanie z `lab02.pdf` (sekcja 2, zapis **ZM**). **Przedstaw w ZM liczby dziesiętne:**

1. `7` i `-7`
2. `12` i `-12`
3. `127` i `-127`
4. `56` i `-56`
5. `32` i `-32`

:::note[Przyjęta szerokość]
Dla przejrzystości kodujemy wszystkie wyniki na **8 bitach**. Oryginał nie wskazuje jednej wymaganej szerokości dla każdego podpunktu.
:::

### Podpowiedź

W ZM pierwszy bit to znak, a pozostałe siedem przedstawia wartość bezwzględną.

<details>
<summary>Pokaż wszystkie rozwiązania (8 bitów)</summary>

| Liczba dziesiętna | ZM, 8 bitów |
|---|---|
| +7 | `00000111` |
| -7 | `10000111` |
| +12 | `00001100` |
| -12 | `10001100` |
| +127 | `01111111` |
| -127 | `11111111` |
| +56 | `00111000` |
| -56 | `10111000` |
| +32 | `00100000` |
| -32 | `10100000` |

</details>

## Jak rozwiązać taki typ zadania od zera?

**To dodatkowy przykład pokazujący sposób rozwiązania. Oryginalne dane z laboratorium i tabela odpowiedzi pozostają powyżej bez zmian.**

1. Aby zapisać liczbę ujemną w ZM, **najpierw ustal szerokość** bitową podaną w zadaniu.
2. Przećwicz przykład pomocniczy `−5` na 8 bitach: siedmiobitowy moduł `5` to `0000101`.
3. Dodaj znak `1` z lewej: `10000101`.
4. Kontrola: najstarszy bit oznacza minus, pozostałe `0000101₂ = 5`. Zatem to rzeczywiście `−5` w ZM.

### Dlaczego wykonujemy właśnie te działania?

W ZM znak i wartość są rozdzielone: łatwo odtworzyć wartość przez odczytanie końcowych `n−1` bitów.

:::caution[Uważaj tutaj]
Nie zapisuj U2 zamiast ZM i nie doklejaj dodatkowego bitu do już ustalonej długości.
:::

### Minisprawdzian po zadaniu

Jak zapisać `+5` w ZM na 8 bitach?

<details>
<summary>Rozwiń rozwiązanie</summary>

`00000101` (bit znaku to 0).

</details>
