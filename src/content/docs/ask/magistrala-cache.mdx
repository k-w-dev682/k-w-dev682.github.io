# Magistrale i pamięć podręczna

**Magistrala** to droga komunikacji używana do przenoszenia danych, adresów lub sygnałów sterujących. W prostych podręcznikowych schematach wyróżnia się magistralę danych, adresową i sterującą.

**Pamięć cache** zmniejsza średni czas dostępu do często używanych informacji. Procesor nie musi za każdym razem pobierać wszystkiego z pamięci RAM.

### Bardzo prosty scenariusz

1. CPU chce odczytać wartość spod pewnego adresu.
2. Sprawdza odpowiednią warstwę cache.
3. Gdy dane są w cache, korzysta z nich (trafienie, *hit*).
4. Jeśli nie ma ich w cache, trzeba sięgnąć niżej, np. do RAM (*miss*).

:::caution[Model naukowy, nie opis konkretnego komputera]
Rzeczywiste hierarchie cache, protokoły zgodności i mechanizmy dostępu są bardziej złożone. Nie znamy szczegółowego zakresu Twojego wykładu.
:::
