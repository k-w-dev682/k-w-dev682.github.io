# Ćwiczenia U1: zapis liczb dodatnich i ujemnych

Oryginalne zadanie z `lab02.pdf` (sekcja 2, zapis **U1**). **Przedstaw w U1 liczby dziesiętne:**

1. `7` i `-7`
2. `12` i `-12`
3. `127` i `-127`
4. `56` i `-56`
5. `32` i `-32`

:::note[Przyjęta szerokość]
Dla przejrzystości kodujemy wszystkie wyniki na **8 bitach**. Oryginał nie wskazuje jednej wymaganej szerokości dla każdego podpunktu.
:::

### Podpowiedź

W U1 odwróć każdy bit ośmiobitowej dodatniej liczby.

<details>
<summary>Pokaż wszystkie rozwiązania (8 bitów)</summary>

| Liczba dziesiętna | U1, 8 bitów |
|---|---|
| +7 | `00000111` |
| -7 | `11111000` |
| +12 | `00001100` |
| -12 | `11110011` |
| +127 | `01111111` |
| -127 | `10000000` |
| +56 | `00111000` |
| -56 | `11000111` |
| +32 | `00100000` |
| -32 | `11011111` |

</details>

## Jak rozwiązać taki typ zadania od zera?

**To dodatkowy przykład pokazujący sposób rozwiązania. Oryginalne dane z laboratorium i tabela odpowiedzi pozostają powyżej bez zmian.**

1. Wybierz ustaloną w poleceniu liczbę bitów. Przykład pomocniczy: **−5 na 8 bitach**.
2. Zapisz `+5 = 00000101`.
3. Odwróć **wszystkie osiem** bitów: `11111010`.
4. W U1 ten wynik oznacza `−5`. Sprawdź odwrotnie: `11111010` → `00000101₂` = 5.

### Dlaczego wykonujemy właśnie te działania?

U1 polega na jednorazowej inwersji każdego bitu, bez dodawania 1.

:::caution[Uważaj tutaj]
Nie wykonuj przypadkowo procedury U2. Pamiętaj, że U1 ma dwa kody zera.
:::

### Minisprawdzian po zadaniu

Zapisz `−1` na 4 bitach w U1.

<details>
<summary>Rozwiń rozwiązanie</summary>

`+1 = 0001`, inwersja → `1110`.

</details>
