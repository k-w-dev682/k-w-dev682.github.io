# Asembler: odczyt zmiennej, dodawanie i zapis

W uproszczonym modelu programu zmienne są przechowywane w pamięci, a operacje wykonujemy na danych przeniesionych do rejestrów.

### Przykład pojęciowy (pseudorozkazy, nie rzeczywiste x86)

```text
LOAD R0, [10]   ; R0 = zawartość pamięci pod adresem 10
LOAD R1, [11]   ; R1 = zawartość pamięci pod adresem 11
ADD  R0, R1     ; R0 = R0 + R1
STORE [12], R0  ; pamięć pod adresem 12 = R0
```

Przyjmij: `pamięć[10]=7`, `pamięć[11]=5`, `pamięć[12]=0`.

| Krok | Rejestr R0 | Rejestr R1 | Pamięć[12] |
|---|---:|---:|---:|
| Start | 0 | 0 | 0 |
| LOAD R0 | 7 | 0 | 0 |
| LOAD R1 | 7 | 5 | 0 |
| ADD R0,R1 | 12 | 5 | 0 |
| STORE | 12 | 5 | 12 |

**Nie myl:** `LOAD` i `STORE` to tutaj **własne nazwy w symulatorze dydaktycznym**. Konkretne rozkazy rzeczywistego procesora mogą wyglądać inaczej.
