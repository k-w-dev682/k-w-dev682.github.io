# Co robi procesor (CPU)?

To **uzupełnienie dydaktyczne**: nie mamy materiałów z wykładu o budowie CPU, więc opisuję jedynie podstawy, które najczęściej pojawiają się na początku architektury systemów komputerowych.

**CPU** (Central Processing Unit) wykonuje rozkazy programu, wykonuje obliczenia i steruje przepływem danych.

| Część CPU | Najprostsza funkcja |
|---|---|
| Jednostka sterująca | Organizuje pobieranie i wykonywanie instrukcji |
| ALU | Dodaje, odejmuje i wykonuje operacje logiczne |
| Rejestry | Bardzo szybkie miejsce na bieżące dane i adresy |
| Licznik rozkazów (PC/IP) | Wskazuje adres następnej instrukcji |
| Pamięć podręczna | Przechowuje często potrzebne dane i instrukcje blisko rdzenia |

:::note[To nie schemat kompletnego procesora]
Rzeczywiste CPU mogą zawierać wiele rdzeni, kolejki, potoki, przewidywanie skoków i inne moduły. Nasz schemat służy wyłącznie do zrozumienia początku działania.
:::
