# Co robi procesor (CPU)?

To **uzupełnienie dydaktyczne**: nie mamy materiałów z wykładu o budowie CPU, więc opisuję jedynie podstawy, które najczęściej pojawiają się na początku architektury systemów komputerowych.

**CPU** (Central Processing Unit) wykonuje rozkazy programu, wykonuje obliczenia i steruje przepływem danych.

| Część CPU | Najprostsza funkcja |
|---|---|
| Jednostka sterująca | Organizuje pobieranie i wykonywanie instrukcji |
| ALU | Dodaje, odejmuje i wykonuje operacje logiczne |
| Rejestry | Bardzo szybkie miejsce na bieżące dane i adresy |
| Licznik rozkazów (PC/IP) | Wskazuje adres następnej instrukcji |
| Pamięć podręczna | Przechowuje często potrzebne dane i instrukcje blisko rdzenia |

:::note[To nie schemat kompletnego procesora]
Rzeczywiste CPU mogą zawierać wiele rdzeni, kolejki, potoki, przewidywanie skoków i inne moduły. Nasz schemat służy wyłącznie do zrozumienia początku działania.
:::

## Zrozum to od początku — StudyLab BLACK Edition

Procesor (CPU) to urządzenie wykonujące instrukcje programu. Sam w sobie nie „zna znaczenia” aplikacji — odczytuje kolejne zakodowane polecenia i manipuluje danymi.

### Pełny przykład: każdy krok ma swoje uzasadnienie

1. Program w pamięci zawiera instrukcje. Przykładowa instrukcja może znaczyć „dodaj wartości z dwóch rejestrów”.
2. Jednostka sterująca koordynuje pobranie i dekodowanie instrukcji.
3. Układy wykonawcze, np. ALU, wykonują działania arytmetyczne i logiczne.
4. Rejestry przechowują wartości i wyniki blisko tych układów. Pamięć RAM zawiera więcej danych, ale dostęp do niej ma inny koszt niż dostęp do rejestru.

### Dlaczego to działa?

Gdy uruchamiasz program, CPU wykonuje mnóstwo prostych rozkazów. Złożone zachowanie aplikacji jest wynikiem ich odpowiedniej kolejności i współpracy z pamięcią.

:::tip[Jak to zapamiętać]
**Powiedz na głos, co pokazuje schemat:** skąd biorą się dane, co zmienia się w każdym kroku i jak sprawdzić końcowy wynik. Jeżeli potrafisz wykonać przykład z innymi liczbami, rozumiesz regułę.
:::

:::caution[Najczęstszy błąd]
Nie myl CPU z RAM ani z całym komputerem. CPU przetwarza dane, RAM przechowuje dane robocze, a pozostałe podzespoły pełnią własne funkcje.
:::
