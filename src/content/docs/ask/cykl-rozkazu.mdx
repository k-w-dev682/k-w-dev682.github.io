# Pobierz → dekoduj → wykonaj

Jednym ze sposobów wyjaśnienia pracy procesora jest **cykl rozkazu**:

1. **Fetch (pobranie):** CPU pobiera instrukcję z pamięci lub pamięci podręcznej.
2. **Decode (dekodowanie):** określa, co oznacza rozkaz i jakie dane są potrzebne.
3. **Execute (wykonanie):** przeprowadza operację, np. dodawanie, odczyt lub zapis.
4. **Zapis wyniku i kolejny rozkaz:** procesor zapisuje wynik zgodnie z instrukcją i przechodzi dalej.

### Przykład

Masz w rejestrze wartość 4, a instrukcja mówi „dodaj 3”. CPU rozpoznaje operację dodawania i nowa wartość rejestru wynosi **7**.

:::note[Uproszczenie]
W nowoczesnym procesorze wiele faz może wykonywać się jednocześnie dla różnych instrukcji. Nasz model jest **sekwencyjny**, przeznaczony dla osoby początkującej.
:::
