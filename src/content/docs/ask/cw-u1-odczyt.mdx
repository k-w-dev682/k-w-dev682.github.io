# Ćwiczenia U1: odczytaj wartość dziesiętną

Oryginalne zadanie z `lab02.pdf` (sekcja 2, zapis **U1**). **Jakim liczbom dziesiętnym odpowiadają poniższe ciągi bitów?**

1. `011011`
2. `111111`
3. `1010101`
4. `0111`
5. `10111`

### Ważna wskazówka

Każdą liczbę odczytujemy **w szerokości podanej w samym zadaniu**: `011011` ma 6 bitów, `1010101` ma 7, a `0111` ma 4. Nie dopisuj dodatkowych bitów znaku przy odczycie.

<details>
<summary>Pokaż odpowiedzi</summary>

| Ciąg bitów w U1 | Wartość dziesiętna |
|---|---:|
| `011011` | 27 |
| `111111` | -0 |
| `1010101` | -42 |
| `0111` | 7 |
| `10111` | -8 |

</details>

:::note[Ujemne zero]
W ZM i U1 pewne ciągi oznaczają `-0`. Wartość liczby nadal wynosi zero, ale kod bitowy jest inny niż dla `+0`.
:::

## Jak rozwiązać taki typ zadania od zera?

**To dodatkowy przykład pokazujący sposób rozwiązania. Oryginalne dane z laboratorium i tabela odpowiedzi pozostają powyżej bez zmian.**

1. Weź oryginalny `1010101` (7 bitów). Najstarszy bit to 1, więc w U1 jest to liczba ujemna.
2. Odwróć **wszystkie 7** bitów: `0101010`.
3. Oblicz dodatnią wartość `0101010₂`: `32+8+2 = 42`.
4. Wynik to **−42**. Zwróć uwagę, że `111111` (6 bitów) jest w U1 ujemnym zerem.

### Dlaczego wykonujemy właśnie te działania?

Po zanegowaniu kodu U1 otrzymujesz zapis dodatniego modułu. W ten sposób odczytujesz znak i wartość.

:::caution[Uważaj tutaj]
Nie odwracaj tylko jednego bitu. Nie dopisuj kolejnego bitu znaku przed operacją.
:::
