# Ćwiczenia U2: zapis liczb dodatnich i ujemnych

Oryginalne zadanie z `lab02.pdf` (sekcja 2, zapis **U2**). **Przedstaw w U2 liczby dziesiętne:**

1. `7` i `-7`
2. `12` i `-12`
3. `127` i `-127`
4. `56` i `-56`
5. `32` i `-32`

:::note[Przyjęta szerokość]
Dla przejrzystości kodujemy wszystkie wyniki na **8 bitach**. Oryginał nie wskazuje jednej wymaganej szerokości dla każdego podpunktu.
:::

### Podpowiedź

W U2 odwróć osiem bitów dodatniej liczby, a następnie dodaj 1.

<details>
<summary>Pokaż wszystkie rozwiązania (8 bitów)</summary>

| Liczba dziesiętna | U2, 8 bitów |
|---|---|
| +7 | `00000111` |
| -7 | `11111001` |
| +12 | `00001100` |
| -12 | `11110100` |
| +127 | `01111111` |
| -127 | `10000001` |
| +56 | `00111000` |
| -56 | `11001000` |
| +32 | `00100000` |
| -32 | `11100000` |

</details>

## Jak rozwiązać taki typ zadania od zera?

**To dodatkowy przykład pokazujący sposób rozwiązania. Oryginalne dane z laboratorium i tabela odpowiedzi pozostają powyżej bez zmian.**

1. Przykład pomocniczy: zapisz **−5** na 8 bitach.
2. Zapisz dodatnie `5` jako `00000101`.
3. Odwróć wszystkie bity → `11111010`.
4. Dodaj 1 → `11111011`. To wynik U2.
5. Sprawdź: najstarszy bit ma wagę −128, pozostałe są dodatnie. Suma dla tego kodu to −5.

### Dlaczego wykonujemy właśnie te działania?

Dodatkowa jedynka jest niezbędna, bo zmienia U1 w U2 i eliminuje ujemne zero.

:::caution[Uważaj tutaj]
Nie zapominaj o dodawaniu 1 i pilnuj dokładnie wymaganej szerokości słowa.
:::

### Minisprawdzian po zadaniu

Zapisz `−2` na 4 bitach w U2.

<details>
<summary>Rozwiń rozwiązanie</summary>

`+2 = 0010`; odwróć `1101`; dodaj 1 → `1110`.

</details>
